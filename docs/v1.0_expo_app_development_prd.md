## 1. 제품 한 줄 정의

**코인미러는 사용자의 과거 거래 내역을 거울처럼 비춰 주는 투자 행동 회고 앱이다.**

매수/매도 추천을 하지 않고, 사용자가 이미 실행한 거래와 직접 입력한 매매 계획·감정·근거를 바탕으로 뇌동매매, 손절 규율, 계획 준수 등 투자 습관을 시각화한다.

## 2. 핵심 포지셔닝

### 2.1 금융 서비스가 아니라 행동 회고 도구

코인미러는 다음을 제공하지 않는다.

- 특정 코인 매수/매도 추천
- 미래 가격 예측
- 포트폴리오 비중 조정 지시
- 자동 주문 또는 거래 실행
- 원금 보장 또는 수익 보장 표현

코인미러가 제공하는 것은 다음이다.

- 과거 거래 데이터 기반 행동 분석
- 매매 전 작성한 계획 대비 실제 실행 비교
- 감정·근거 태그 기반 자기 인식 리포트
- 주간 단위 투자 습관 회고
- 향후 확장 가능한 스코어 시스템

### 2.2 MVP 운영 원칙

| 원칙 | 내용 |
|---|---|
| File-First | 초기 MVP는 CSV/PDF 업로드와 수동 입력을 우선 구현하되, API 연동을 후속 핵심 기능으로 확장 가능하게 설계 |
| Local-First | 민감 거래 데이터는 가능하면 디바이스 내부 저장 우선 |
| Batch-First | 실시간 알림보다 일간/주간 리포트 중심 |
| Compliance-First | 모든 문구는 사후 분석/행동 회고 표현으로 제한 |
| Score-Extensible | 스코어는 향후 계속 추가될 수 있도록 모듈형 구조로 설계 |
| Subscription-Simple | 요금제는 Free와 구독관리 플랜 2개로 단순화 |

## 3. MVP 목표

### 3.1 1차 출시 목표

1차 앱의 목표는 **완성된 투자 플랫폼**이 아니라, 사용자가 자신의 매매 습관을 계속 기록하고 확인하고 싶게 만드는 최소 루프를 만드는 것이다.

### 3.2 MVP 핵심 사용자 루프

```text
거래 내역 입력/업로드
→ 매매 근거·감정·목표/손절 기록
→ 기본 스코어 확인
→ 주간 거울 리포트 확인
→ 다음 주 원칙 설정
→ 다시 기록
```

### 3.3 MVP 성공 기준

| 지표 | 목표 |
|---|---|
| 첫 기록 완료율 | 온보딩 후 5분 내 첫 거래/일기 기록 완료 |
| 주간 회고 완료율 | 가입 후 7일 내 1회 이상 주간 회고 작성 |
| 리텐션 훅 | 스코어 변화/스트릭/리포트 때문에 재방문 유도 |
| 규제 안정성 | 앱 내 문구에서 추천·예측·수익보장 표현 제거 |

### 4.1 핵심 타깃

| 페르소나 | 문제 | 코인미러 제공 가치 |
|---|---|---|
| 뇌동매매 반복 투자자 | 급등 코인 추격, 손절 지연, 감정적 재진입 | 행동 패턴을 숫자와 리포트로 직면 |
| 거래 기록을 남기고 싶은 투자자 | 엑셀/메모장 관리가 귀찮음 | 모바일에서 간단히 기록하고 주간 회고 |

## 6. MVP 기능 명세

## 6.1 온보딩

### 목적
사용자에게 코인미러의 성격을 명확히 각인한다.

### 첫 화면 — 서비스 소개/가치 이해

앱 첫 진입 화면은 단순 로그인/업로드 버튼이 아니라, 사용자가 **“이 앱으로 무엇을 할 수 있는지”**를 10초 안에 이해하도록 구성한다.

#### 핵심 헤드라인

> 내 거래를 거울처럼 비춰 보고,  
> 반복되는 투자 습관을 관리하세요.

#### 설명 문구

> 코인미러는 CSV/PDF 거래내역과 직접 기록한 매매 근거를 바탕으로 뇌동매매, 손절 규율, 계획 준수율을 보여주는 투자 행동 회고 앱입니다.

#### 사용자가 할 수 있는 일

| 기능 | 설명 | 플랜 |
|---|---|---|
| 거래내역 가져오기 | CSV/PDF 거래내역 또는 수동 입력으로 과거 거래를 정리 | Free |
| 기본 스코어 확인 | 뇌동매매, 손절 규율, 익절 습관, 계획 준수율 확인 | Free |
| 주간 거울 리포트 | 이번 주 매매 행동의 좋아진 점과 주의할 점 확인 | Free |
| 목표 세팅/진척 관리 | 월간/주간 투자 습관 목표를 세우고 진행률 확인 | 구독관리 |
| PDF 정밀 리포트 | 목표 진척과 스코어 변화를 월간 PDF로 저장 | 구독관리 |
| 종목 정보 모아보기 | 보유/관심 종목의 뉴스·거래소 공지·이벤트 확인 | 구독관리 |

#### 첫 화면 CTA

- `코인미러 시작하기`
- `샘플 화면 먼저 보기`
- `투자 조언 아님 고지 확인`

#### UX 원칙

- 첫 화면에서 바로 “매수/매도 추천 앱”처럼 보이면 안 된다.
- `기록`, `회고`, `습관 관리`, `목표 진척` 키워드를 전면에 둔다.
- Free에서도 충분히 시작할 수 있음을 명확히 보여준다.
- 구독관리 플랜은 첫 화면에서 과도하게 판매하지 않고, “목표 관리가 필요할 때 확장”되는 구조로 설명한다.

### 핵심 메시지

> 코인미러는 투자 조언 앱이 아닙니다.  
> 이미 완료된 거래와 사용자가 직접 작성한 기록을 바탕으로 투자 습관을 돌아보는 회고 도구입니다.

### 화면 구성

1. 제품 소개
2. 데이터 입력 방식 선택
3. 면책 고지 및 동의
4. 첫 거래 기록 또는 샘플 데이터 체험

### 필수 CTA

- `CSV로 시작하기`
- `PDF 명세서로 시작하기`
- `직접 입력하기`
- `샘플 데이터로 둘러보기`

- `그냥/느낌` 태그도 숨기지 않는다. 오히려 뇌동매매 분석의 핵심 데이터다.

## 6.3 거래 내역 파일 업로드 — CSV/PDF

### MVP 범위

초기에는 국내 거래소 KRW 마켓의 **CSV와 PDF 거래내역서**를 우선 지원한다. 거래소마다 CSV 제공 방식이 다르고, 사용자가 모바일/이메일/고객센터에서 PDF 거래내역서만 확보하는 경우가 있으므로 PDF 업로드도 1차 설계에 포함한다.

1. 업비트 CSV
2. 빗썸 CSV
3. 업비트/빗썸 PDF 거래내역서
4. 기타 거래소 CSV/PDF는 `직접 매핑` 또는 `준비 중` 처리

### 파일 유형별 처리 원칙

| 파일 유형 | MVP 처리 | 비고 |
|---|---|---|
| CSV | 앱/서버에서 구조화 파싱 | 가장 우선 구현 |
| PDF 텍스트형 | 서버 또는 Edge Function에서 텍스트 추출 후 거래 테이블 파싱 | 모바일 로컬 파싱보다 서버 파싱 권장 |
| PDF 스캔형/이미지형 | MVP에서는 `인식 불가` 처리, 향후 OCR 도입 | 잘못된 추출 방지를 위해 수동 확인 필수 |
| 엑셀 XLSX | 후순위 | 거래소 제공 빈도 확인 후 결정 |

### 처리 흐름

```text
파일 선택
→ 파일 유형 감지
→ CSV 컬럼 인식 또는 PDF 텍스트/테이블 추출
→ 거래 내역 미리보기
→ 오류/누락 행 표시
→ 가져오기 확정
→ 로컬 저장
→ 스코어 재계산
```

### 오류 UX

| 상황 | 사용자 메시지 |
|---|---|
| 컬럼 인식 실패 | 파일 형식을 확인하지 못했어요. 거래소 선택 후 다시 업로드해 주세요. |
| PDF 텍스트 추출 실패 | 이 PDF는 이미지/스캔본이라 자동 인식이 어려워요. CSV 파일 또는 수동 입력을 이용해 주세요. |
| 숫자 파싱 실패 | 일부 거래 금액을 읽지 못했어요. 문제가 있는 행만 제외하고 가져올 수 있어요. |
| 중복 거래 감지 | 이미 가져온 거래가 포함되어 있어 중복 항목은 제외했어요. |

## 6.4 홈 대시보드

### 목적
앱을 열자마자 “이번 주 내 투자 습관 상태”를 이해시킨다.

### 구성 요소

1. 투자 체력 종합점수 카드

## 6.5 기본 스코어 MVP

스코어 시스템은 향후 계속 개발·추가될 예정이므로, MVP에서는 최소 스코어만 안정적으로 구현한다.

### 1차 구현 스코어

| ID | 스코어 | MVP 노출 | 비고 |
|---|---|---:|---|
| S01 | 뇌동매매 지수 | O | 핵심 바이럴/자기인식 지표 |
| S02 | 손절 규율 점수 | O | 손절가 입력 데이터 필요 |
| S03 | 익절 습관 점수 | O | 보유기간/손익 비대칭 기반 |
| S09 | 계획 준수율 | O | 기록 습관 유도 핵심 |
| S10 | 투자 체력 종합점수 | O | 홈 대표 점수 |

### 향후 확장 예정

- 기본 스코어 10종 전체
- 확장 스코어 20종
- 파생/히든/마일스톤 스코어 20종
- XP 기반 언락 시스템
- 스코어 검증 배지
- 백테스팅 기반 스코어 강등/폐기 시스템

### 중요한 개발 원칙

스코어는 하드코딩하지 않고 `scoreDefinition` 기반으로 구성한다.

```ts
type ScoreDefinition = {
  id: string;
  name: string;
  category: 'risk' | 'discipline' | 'composite' | 'milestone';
  status: 'active' | 'beta' | 'planned';
  requiredInputs: string[];
  minSampleSize: number;
  description: string;
};
```

### 점수 표시 원칙

| 상태 | UI 표시 |
|---|---|
| 충분한 데이터 있음 | 점수와 해석 표시 |
| 거래 10건 미만 | `측정 중` |
| 필수 입력 부족 | `기록이 더 필요해요` |

## 6.6 주간 거울 리포트

### 목적
앱의 리텐션 핵심 기능. 사용자가 매주 자신의 행동을 돌아보게 만든다.

### 리포트 구성

1. 이번 주 요약
2. 가장 좋아진 점
3. 가장 주의할 점
4. 대표 거래 사례 1~3개
5. 다음 주 원칙 체크리스트

### 예시 문구

> 이번 주에는 총 12건의 거래가 기록됐어요.  
> 그중 7건은 매매 근거 태그가 없었고, 4건은 급등 이후 3분 이내에 체결됐어요.  
> 코인미러는 이 패턴을 뇌동매매 위험 신호로 분류했어요.

### AI 사용 범위

Gemini 3.5 Flash 또는 유사 저비용 모델은 **정량 데이터 요약 문장 생성**에만 사용한다.

AI가 해도 되는 것:

- 거래 행동 요약
- 기록 기반 회고 문장 작성
- 감정 태그 패턴 설명

AI가 하면 안 되는 것:

- 미래 가격 예측
- 매수/매도 추천
- 특정 코인 비중 제안
- 확정적 수익 개선 약속

## 6.8 구독 시스템 — Free / 구독관리 플랜

### 기본 방향

요금제는 복잡하게 쪼개지 않고 **Free**와 **구독관리 플랜** 2개로만 구성한다.

초기 제품의 핵심 목표는 무료 사용자도 거래 기록과 기본 회고 가치를 충분히 경험하게 만들고, 더 깊은 목표 관리·진척 추적·추가 스코어·보유 종목 정보가 필요한 사용자를 구독관리 플랜으로 전환시키는 것이다.

### 플랜 구조

| 플랜 | 목적 | 제공 가치 |
|---|---|---|
| Free | 코인미러의 기본 회고 루프 체험 | 거래 기록, CSV/PDF 업로드, 기본 스코어, 주간 요약, 기본 원칙 체크인 |
| 구독관리 | 투자 습관 개선을 장기 관리 | 목표 세팅, 진척 추적, PDF 정밀 리포트, 추가 스코어, 보유 종목 정보, 고급 리포트 |

### Free 제공 범위

Free에서도 제품의 핵심 루프는 가능해야 한다.

- 수동 거래 기록
- CSV/PDF 거래내역 업로드
- 기본 거래 리스트/상세 화면
- 기본 스코어 MVP
  - S01 뇌동매매 지수
  - S02 손절 규율 점수
  - S03 익절 습관 점수
  - S09 계획 준수율
  - S10 투자 체력 종합점수
- 기본 주간 거울 리포트
- 기본 원칙 체크인
- 샘플 데이터 체험
- 로컬 데이터 삭제/내보내기

### 구독관리 플랜 제공 범위

구독관리 플랜은 “더 많은 기능”보다 **목표를 세우고, 지키고, 진척을 확인하는 관리형 경험**에 초점을 둔다.

#### 1. 목표 세팅

- 월간/주간 투자 습관 목표 설정
- 예시 목표
  - `근거 없는 매수 비율 30% 이하로 낮추기`
  - `손절가 입력 거래 비율 80% 이상 유지하기`
  - `급등 직후 30분 내 매수 줄이기`
  - `이번 달 무계획 물타기 0회`
- 목표별 기준값, 기간, 성공 조건 설정

#### 2. 진척 과정 시각화

- 목표별 진행률 카드
- 주간 개선 추이
- 연속 준수 스트릭
- 실패/이탈 구간 회고
- 목표 달성 배지 또는 졸업 카드

#### 3. PDF 정밀 리포트

PDF 정밀 리포트는 별도 1회성 상품이 아니라 **구독관리 플랜에 포함**한다.

- 월간 목표 회고 PDF
- 목표별 진척률
- 스코어 변화
- 대표 거래 사례
- 다음 달 목표 추천이 아닌 `목표 후보 제안` 형태의 회고 문장
- 모든 PDF 하단에 투자 자문 아님 고지 포함

#### 4. 추가 스코어 이용

Free는 기본 스코어 중심, 구독관리는 확장 스코어와 파생 스코어를 단계적으로 제공한다.

- 확장 스코어 20종 중 우선순위 높은 지표부터 제공
- 파생/히든/마일스톤 스코어 일부 제공
- 스코어 도감
- 베타/측정 중/검증됨 배지
- 단, 스코어가 투자 추천처럼 보이면 안 되며 행동 회고 지표로만 표현

#### 5. 투자 종목 정보

구독관리 플랜에서는 사용자가 보유하거나 관심 등록한 종목에 대한 정보를 볼 수 있게 한다.

허용 범위:

- 보유/관심 종목 뉴스 모아보기
- 거래소 공지/이벤트 정보
- 상장, 점검, 에어드랍, 스테이킹 등 이벤트 알림
- 종목별 내 거래 기록과 뉴스 타임라인 매칭

금지 범위:

- 매수/매도 추천
- 목표가 제시
- 상승/하락 예측
- 특정 종목 비중 조정 제안

### 구독 관리 화면

설정 탭 하위에 `구독 관리` 화면을 둔다.

화면 구성:

1. 현재 플랜 상태
2. Free vs 구독관리 비교표
3. 구독관리 플랜 핵심 혜택
4. 결제/복원/해지 버튼
5. 구독 권한 동기화 상태
6. 환불 및 약관 안내

### Paywall 진입 지점

구독 전환은 사용자가 가치를 느낀 순간에 자연스럽게 노출한다.

| 진입 지점 | 메시지 방향 |
|---|---|
| 추가 스코어 잠금 카드 | 더 세밀한 습관 지표를 확인하려면 구독관리가 필요해요 |
| 목표 2개 이상 생성 | 여러 목표를 동시에 관리하려면 구독관리가 필요해요 |
| 월간 PDF 생성 | 이번 달 목표 진척 리포트는 구독관리에서 생성할 수 있어요 |
| 종목 정보 탭 | 보유 종목 뉴스와 이벤트 모아보기는 구독관리 기능이에요 |

### 기술 구현 원칙

앱스토어/플레이스토어 출시를 고려해 구독 권한 구조를 먼저 분리한다.

| 영역 | 권장 구현 |
|---|---|
| 결제 SDK | RevenueCat 우선 검토 |
| 권한 관리 | `entitlement: free | subscription_management` |
| 구독 상태 저장 | 로컬 캐시 + 서버 동기화 |
| 기능 잠금 | Feature Flag 기반 |
| 결제 복원 | iOS/Android 복원 버튼 필수 |

## 10. 컴플라이언스 카피 가이드

## 10.1 전역 고지 문구

앱 가입, 리포트, 스코어 상세 하단에 다음 문구를 반복 노출한다.

> 본 서비스는 과거 거래 데이터와 사용자가 직접 입력한 기록을 기반으로 투자 습관을 요약하는 회고 도구입니다. 특정 가상자산의 매수·매도 추천, 가격 예측, 투자 자문, 원금 또는 수익 보장을 제공하지 않습니다.

## 10.2 허용 표현

- `기록된 거래 기준으로`
- `과거 행동 패턴상`
- `이번 주 매수 기록 중`
- `계획과 실제 실행이 달랐던 지점`
- `주의 신호로 분류됩니다`
- `다음 회고 때 확인해 보세요`

## 10.3 금지 표현

- `지금 사세요`
- `지금 팔아야 합니다`
- `상승 가능성이 높습니다`
- `이 코인은 위험합니다`
- `비중을 줄이세요`
- `수익률을 높일 수 있습니다`
- `손실을 피하려면 이렇게 하세요`

## 13. 개발자에게 전달할 핵심 주의사항

1. **스코어는 계속 늘어난다.** 화면과 데이터 구조를 고정 5개 스코어 기준으로 만들면 안 된다.
2. **추천처럼 보이는 문구는 금지한다.** 모든 문장은 과거 데이터 회고형이어야 한다.
3. **파일 업로드가 MVP 핵심이다.** CSV뿐 아니라 PDF 거래내역서도 고려하고, 두 입력을 같은 표준 Trade 포맷으로 정규화해야 한다.
4. **API 연동은 후속 핵심 기능이다.** MVP에서 실시간 API까지 만들지 않더라도, 데이터 모델과 import pipeline은 Read-Only API 동기화를 전제로 열어 둬야 한다.
5. **민감 데이터는 로컬 우선이다.** 서버 저장은 사용자가 명시적으로 동의한 요약 데이터부터 시작한다.
6. **점수가 안 나오는 상태도 UX다.** 표본 부족 시 억지 점수를 만들지 말고 `측정 중`으로 기록을 유도한다.
7. **앱은 금융 차트 앱보다 웰니스 앱에 가깝다.** 사용자를 압박하지 않고 자기 인식을 돕는 톤을 유지한다.

## 15. 결론

코인미러 앱 개발의 1차 목표는 거창한 실시간 투자 플랫폼이 아니라, **CSV/PDF/수동 기록 → 기본 스코어 → 주간 회고 → 원칙 체크인 → Read-Only API 확장**으로 이어지는 초경량 행동 회고 루프를 만드는 것이다.

Expo와 reusables 디자인 시스템은 빠른 MVP 제작에 적합하며, 스코어 시스템은 향후 지속 확장될 핵심 자산이므로 초기부터 모듈형 구조로 설계해야 한다.

가장 중요한 기준은 다음 세 가지다.

1. **투자 추천처럼 보이지 않을 것**
2. **사용자가 기록을 계속하고 싶게 만들 것**
3. **스코어 확장을 전제로 개발할 것**
