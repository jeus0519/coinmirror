**AI 행동코칭 기준**: 2026-09-07 이후 active 문서는 분석 화면 순서를 `기록 분석 → 거래 개요 → AI 행동코칭 → 내 예상 vs 기록 → 행동 점수 → 투자거울 타입`으로 둔다. AI는 행동 회고 문장 생성에만 사용하며 원본 거래내역/PDF 비밀번호/개별 체결 원문을 사용하지 않는다.

세부 구현 문서가 PRD와 충돌하면 해당 기능의 최신 Product Spec을 우선하고 PRD를 함께 갱신한다.

프로토타입은 현재 기준 문서보다 우선하지 않는다. 구현이 문서와 다르면 `QUALITY_SCORE.md`와 Tech Debt에 차이를 기록한다.

## 5. 히스토리 보관 규칙

`docs/history/`에는 다음을 보관한다.

- 새 버전으로 대체된 PRD·proposal·risk·score 문서
- 폐기되거나 방향이 바뀐 Product Spec
- 과거 의사결정의 근거를 보존할 필요가 있는 문서

히스토리 문서는 수정하지 않는다. 현재 문서에서 직접 기준으로 링크하지 않고, 필요할 때만 비교 자료로 사용한다.

완료된 실행 계획은 `docs/history/`가 아니라 `docs/exec-plans/completed/`에 보관한다.

## 6. 문서 변경 규칙

1. 기능 결정은 Product Spec에 먼저 반영한다.
2. 범위·요금제·핵심 루프가 바뀌면 PRD와 proposal을 함께 갱신한다.
3. 규제/데이터 경계가 바뀌면 risk spec과 SECURITY를 함께 갱신한다.
4. 코드가 문서보다 앞서면 `QUALITY_SCORE.md`에 드리프트를 기록한다.
5. 대체된 버전은 삭제하지 않고 history로 이동한다.
6. 새 문서·스펙은 파일명에 버전을 포함한다.
