# PRODUCT_SENSE

## 한 줄 정의

코인 투자자가 업비트 PDF/CSV 거래 기록과 자기인식 답변을 비교하고, **AI 행동코칭**으로 다음 달에 줄여볼 행동과 유지할 행동을 정리하도록 돕는 웹 우선 데이터 기반 회고 앱.

## 왜 만드는가

- 투자자는 자신의 거래 빈도·시간대·손실 습관을 실제와 다르게 기억할 수 있다.
- 설문 1회와 선택 MBTI로 자기인식을 수집하고, 거래 데이터 업로드 후 AI 행동코칭이 데이터 기반 회고 질문을 먼저 정리하는 것이 빠른 아하모먼트를 만든다는 가설.
- 장기 가치는 더 많은 점수가 아니라 사용자가 고른 원칙과 12주 변화 추적에서 나온다.

## 핵심 신념

상세 배경과 논거는 [docs/design-docs/core-beliefs.md](design-docs/core-beliefs.md) 참고. 요약:

1. 핵심 분석은 반복 입력 없이 동작해야 한다. 선택적 기록이 있더라도 30초 내 끝나야 한다.
2. 실시간 시세/차트를 앱의 중심에 두지 않는다 — 이 앱은 트레이딩 툴이 아니라 웹 우선 회고 툴
3. 패턴을 사용자에게 "판단"이 아니라 "관찰"로 보여준다 (예: "당신은 손실 후 24시간 내 재진입하는 경향이 있습니다")
4. 분석 화면의 주역은 거래 개요 직후 나오는 AI 행동코칭이며, 행동 점수와 투자거울 타입은 근거와 요약으로 이어진다.
5. 모든 고객 노출 점수는 높을수록 절제·규율 상태가 양호하도록 방향을 통일한다.
6. 수익률이 아니라 행동 변화와 자기인식 정확도를 관리한다.

## 기능 스펙 인덱스

개별 기능 스펙은 [docs/product-specs/](product-specs/index.md) 참고.

## 비목표 (Non-goals)

- 실시간 시세/차트 제공 (다른 앱의 역할)
- 자동매매, 시그널 제공
- 투자 자문

## 분석 화면 확정 흐름

2026-09-07 기준 분석 화면은 다음 순서를 따른다.

```text
기록 분석 → 거래 개요 → AI 행동코칭 → 내 예상 vs 기록 → 행동 점수 → 투자거울 타입 → 그 외 상세/구독/피드백
```

AI 행동코칭은 투자 조언이 아니라 과거 거래 기록과 자기인식 답변을 바탕으로 한 행동 회고다. 원본 PDF/CSV, PDF 비밀번호, 개별 체결 원문, 종목명, 금액/수량은 AI 입력으로 보내지 않고, 브라우저에서 계산한 요약 지표와 선택 MBTI/진단 답변만 사용한다.
