# PRODUCT_SENSE

## 한 줄 정의

코인 투자자가 온보딩에서 예상한 투자거울 타입과 실제 거래소 기록 기반 타입의 차이를 비교하고, 반복되는 **행동심리학적 편향**을 스스로 인지하도록 돕는 웹 우선 데이터 기반 회고 앱.

## 왜 만드는가

- 투자자는 자신의 거래 빈도·시간대·손실 습관을 실제와 다르게 기억할 수 있다.
- 설문 1회만으로 예상 투자거울 타입을 먼저 보여주고, 거래 데이터 업로드 후 기록된 타입과의 갭을 보여주는 것이 빠른 자기인식의 출발점이라는 가설.
- 장기 가치는 더 많은 점수가 아니라 사용자가 고른 원칙과 12주 변화 추적에서 나온다.

## 핵심 신념

상세 배경과 논거는 [docs/design-docs/core-beliefs.md](design-docs/core-beliefs.md) 참고. 요약:

1. 핵심 분석은 반복 입력 없이 동작해야 한다. 선택적 기록이 있더라도 30초 내 끝나야 한다.
2. 실시간 시세/차트를 앱의 중심에 두지 않는다 — 이 앱은 트레이딩 툴이 아니라 웹 우선 회고 툴
3. 패턴을 사용자에게 "판단"이 아니라 "관찰"로 보여준다 (예: "당신은 손실 후 24시간 내 재진입하는 경향이 있습니다")
4. 첫 화면의 주역은 숫자 점수보다 투자거울 타입이며, 점수는 근거로 둔다.
5. 모든 고객 노출 점수는 높을수록 절제·규율 상태가 양호하도록 방향을 통일한다.
6. 수익률이 아니라 행동 변화와 자기인식 정확도를 관리한다.
