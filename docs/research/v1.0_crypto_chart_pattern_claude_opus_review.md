# v1.0 차트 패턴 리서치 — Claude Opus 최종 검토 기록

- **검토 모델:** Claude Opus 5 (`claude-opus-5`)
- **검토 방식:** Claude Code CLI 실제 호출, 읽기 전용 1회 검토
- **대상:** `v1.0_crypto_chart_pattern_research.md`
- **최종 판정:** **PASS**

## 검토 통과 항목

1. 규칙 기반 기술분석의 표본 내 결과와 재량적 차트 도형의 보편 승률을 분리했다.
2. 검증되지 않은 인플루언서별 방법론·성과 주장을 제거하고, 원자료 감사 결과로만 남겼다.
3. 고정 승률을 암시하지 않고, OOS·비용·신뢰구간·부트스트랩을 포함한 검증 프로토콜로 전환했다.
4. Coinmirror 적용 시 투자 조언 오인, 레버리지 청산, 과적합·사후편향, 국내 규제 검토 리스크를 명시했다.

## 반영한 보완사항

- 2016–2018 이동평균 연구의 8.76% 수치는 초록 대조 자료로 제한하고, 짧은 단일 사이클 표본·원문 재현 전·다중검정 보정 미확인을 함께 표기했다.
- 거래소 교육자료는 성과 근거가 아닌 개념 설명용으로 한정했다.
- Coinmirror의 30/100건 표기 기준은 통계적으로 도출된 임계값이 아니라 보수적 제품 운영 규칙임을 명시했다.

## 잔여 주의사항

- 이 문서는 패턴 간 실제 승률 랭킹을 제공하지 않는다. BTC·ETH의 사전 등록된 규칙, 비용 포함, OOS 분리 백테스트가 끝난 뒤에만 실측 비교를 추가한다.
- 인플루언서 자료는 본인 도메인/공식 채널의 원본과 발행일, 규칙 정의를 확보할 때까지 근거로 인용하지 않는다.
