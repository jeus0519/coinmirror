# v7.0 코인미러 서비스 제안서

- **상태**: 현재 사업 기준
- **기준일**: 2026-08-15
- **제품 기준**: [v2.0 PRD](v2.0_coinmirror_product_prd.md)

## 1. 한 줄 제안

코인미러는 거래소 거래 데이터를 자동 분석해 투자자의 반복 행동과 자기인식 차이를 보여주고, 선택한 원칙의 변화를 장기 관리하는 **투자 습관 회고 구독 서비스**다.

## 2. 문제와 해결

| 문제                                                                 | 코인미러의 해결                                                               |
| -------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| 투자자는 자신의 거래 빈도·시간대·손실 습관을 정확히 기억하기 어렵다. | 온보딩의 자기 예상과 CSV 실측을 비교한다.                                     |
| 손익 화면은 행동 원인을 보여주지 않는다.                             | 추격매수·물타기·복구매수·새벽거래 등 자동 행동 스코어와 근거 거래를 제공한다. |
| 일기형 앱은 반복 입력 마찰이 높다.                                   | 설문 1회와 CSV/API 데이터만으로 핵심 분석이 돌아간다.                         |
| 단발 분석은 행동 변화를 유지시키지 못한다.                           | 구독관리에서 12주 추세, 원칙 준수, PDF 리포트를 제공한다.                     |

## 3. 핵심 가치 사다리

1. **가치 이해** — 투자 추천이 아닌 자기 행동 거울임을 설명
2. **내 투자 거울 설정** — 객관식 설문으로 기준과 자기 예상 수집
3. **예상 타입 카드** — 설문 직후 CSV 없이 공유 가능한 예상 투자거울 타입 공개
4. **무료 자동 분석** — PDF/CSV 거래내역 업로드 후 기록된 타입, 예상과의 갭, 근거 점수 공개
5. **원칙 선택** — 사용자가 프리셋 원칙을 직접 선택
6. **구독 관리** — 주간·월간 변화, 스트릭, 이메일 PDF 리포트, 추가 분석

## 4. 요금제

요금제는 **Free + 구독관리** 두 개로 유지한다.

| 플랜     | 역할                  | 핵심 제공 가치                                                                                      |
| -------- | --------------------- | --------------------------------------------------------------------------------------------------- |
| Free     | 제품의 핵심 효용 검증 | 온보딩 설문, 예상 투자거울 타입 카드, CSV/샘플 분석, 기록된 타입+근거 점수, 예상 vs 실제, 기본 원칙 |
| 구독관리 | 장기 변화 관리        | 구독 스코어 7종, 12주 추세, 원칙 최대 2개, 진척·스트릭, 이메일 PDF 리포트, 보유/관심 종목 정보      |

### 제외된 과거 안

- PDF 리포트 별도 일회성 상품
- 4주 챌린지 별도 기수제 상품
- 평생권/알럼나이 등 다단계 요금제

이 항목들은 초기 사업 가설로 `docs/history/v6.0_cto_business_proposal.md`에 보존하며, 현재 제품 범위에는 포함하지 않는다.

## 5. 전환 구조

무료 사용자에게 먼저 다음 아하모먼트를 제공한다.

> “나는 한 달 11~30회 거래한다고 예상했지만, 기록에는 월평균 74회가 남아 있었습니다.”

구독 전환은 더 많은 카드의 잠금 해제보다 다음 가치에 집중한다.

- 이 차이가 12주 동안 줄어드는가
- 가장 낮은 습관이 회복되는가
- 내가 선택한 원칙을 실제로 지켰는가
- 월간 변화가 PDF로 누적되는가

## 6. 운영 모델

- 업비트 고객센터 PDF + CSV 거래내역 업로드를 MVP 핵심 입력으로 확정. PDF는 실제 고객센터 발급 파일 기반으로 1차 지원한다.
- 웹 우선. Expo 웹 타겟(`npm run web`)을 1순위로 검증하고 네이티브 앱은 후속이다.
- Batch-First = 서버 주간 배치 + 이메일 리포트 발송.
- Local-First = 원본 거래 데이터는 기기/분석 세션에 두고 서버에는 최소 집계만 보관한다.
- Read-Only API는 후속 자동화 경로
- 주문·출금·자동매매 없음
- AI는 결정론적 산출 결과를 자연어로 요약하는 데만 사용
- 실시간 웹소켓 감시와 매매 개입 알림 없음

## 7. 수익화 가설

초기 검증 항목:

- 무료 분석 완료 사용자 중 재분석 의향
- 4주 변화 추적에 대한 지불 의향
- 이메일 PDF 리포트와 원칙 관리 중 전환 기여도가 높은 기능
- 적정 월 구독 가격과 무료 분석 횟수

가격은 사용자 인터뷰와 결제 의향 테스트 전에는 확정하지 않는다. 과거 제안서의 19,900원 등 숫자는 현재 확정 가격이 아니다.

## 8. 차별점

1. 수익률 추천이 아니라 행동 데이터만 다룬다.
2. 자기 예상과 실제 기록의 차이를 첫 경험으로 만든다.
3. 지속 입력 없이 거래소 데이터로 핵심 스코어를 자동 산출한다.
4. 구독 가치는 점수 개수가 아니라 장기 변화와 원칙 관리다.
5. 한국 거래소 CSV와 원화마켓 사용 맥락을 우선 지원한다.

## 8.5 유통 전략

1. **공유 카드 기반 획득**: 예상 타입 카드는 CSV 없이 생성되므로 초기 바이럴 루프를 만들 수 있다. 공유 카드에는 점수·금액·수익률·종목명을 넣지 않는다.
2. **창업자 보유 채널 활용**: 『Do it! GA4』 독자, 스파르타 수강생, 진행 중인 20강을 초기 유입 채널 후보로 둔다.
3. **미결 질문**: 콘텐츠 파이프라인을 앱 이후 순차가 아니라 유입 채널로서 동시 진행할지 결정해야 한다.

## 9. 리스크

- CSV 파싱 실패가 첫 경험을 훼손할 수 있음
- 스코어가 투자 성과 평가로 오인될 수 있음
- 표본 부족 사용자는 초기 가치가 약할 수 있음
- 장기 변화 가치가 검증되지 않으면 구독 유지가 어려움
- 민감한 거래 데이터를 다루므로 Local-First와 최소 수집이 필수

## 10. 사업 검증 KPI

- 랜딩 → 설문 시작률
- 설문 → PDF/CSV 업로드율
- CSV 파싱 성공률
- 첫 분석 완료율
- 예상 타입 카드 공유/저장 클릭률
- 공유 카드 → PDF/CSV 업로드 전환율
- 예상 vs 실제 카드 공유/확인률
- 4주 재분석률
- Free → 구독관리 전환율
- 3개월 구독 유지율
- 지원 요청 건수와 1인 운영 시간

월 매출보다 먼저 핵심 루프의 재사용성과 낮은 운영 부담을 검증한다.
