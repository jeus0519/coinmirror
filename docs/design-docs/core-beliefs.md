# Core Beliefs

이 문서가 바뀌면 `docs/PRODUCT_SENSE.md`의 요약도 함께 갱신한다.

## 1. 회고는 마찰이 없어야 습관이 된다

매매 직후 30초 안에 기록을 마칠 수 없다면 기능이 아니라 방해물이다. 필드는 최소한으로, 기본값은 최대한 미리 채운다.

## 2. 이 앱은 트레이딩 툴이 아니다

실시간 시세, 차트, 호가창을 앱의 중심 화면에 두지 않는다. 이런 요소는 즉흥적 매매(FOMO)를 강화하는 방향으로 작동하기 쉽고, 이 앱의 목적(회고)과 상충한다.

## 3. 패턴은 "관찰"로 보여주고 "훈계"로 보여주지 않는다

"또 손절하셨네요" 같은 판단형 메시지 대신 "최근 5번의 매도 중 4번이 −5% 이내 손절이었습니다" 같은 관찰형 문장을 쓴다. 사용자가 스스로 결론에 도달하게 한다.

## 4. 데이터는 사용자 소유

투자 기록은 민감한 개인 재무 데이터다. 내보내기(export)를 항상 가능하게 하고, 삭제 요청을 지원한다.

## 근거가 부족한 가정 (검증 필요)

- 감정 라벨링(공포/탐욕/FOMO 태깅)이 실제로 행동 변화로 이어지는지는 아직 검증되지 않음 — 초기 사용자 피드백으로 확인할 것.
