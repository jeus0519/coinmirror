# Core Beliefs

이 문서가 바뀌면 `docs/PRODUCT_SENSE.md`의 요약도 함께 갱신한다.

## 1. 회고는 반복 입력 없이도 시작돼야 한다

핵심 스코어는 온보딩 설문 1회와 거래소 데이터만으로 산출한다. 수동 기록은 선택 기능으로 두고, 제공하더라도 30초 안에 마칠 수 있어야 한다.

## 2. 이 앱은 트레이딩 툴이 아니다

실시간 시세, 차트, 호가창을 앱의 중심 화면에 두지 않는다. 이런 요소는 즉흥적 매매(FOMO)를 강화하는 방향으로 작동하기 쉽고, 이 앱의 목적(회고)과 상충한다.

## 3. 패턴은 "관찰"로 보여주고 "훈계"로 보여주지 않는다

"또 손절하셨네요" 같은 판단형 메시지 대신 "최근 5번의 매도 중 4번이 −5% 이내 손절이었습니다" 같은 관찰형 문장을 쓴다. 사용자가 스스로 결론에 도달하게 한다.

## 4. 데이터는 사용자 소유

투자 기록은 민감한 개인 재무 데이터다. 내보내기(export)를 항상 가능하게 하고, 삭제 요청을 지원한다.

## 5. 자기 예상과 실제의 차이가 첫 아하모먼트다

사용자가 생각한 거래 빈도·시간대·승률과 실제 CSV 기록을 중립적으로 비교한다. "틀렸다"가 아니라 "예상과 기록의 차이"로 표현한다.

## 근거가 부족한 가정 (검증 필요)

- 예상 vs 실제 카드가 첫 분석 완료율과 4주 재분석률을 높이는지는 사용자 테스트로 검증할 것.
- 프리셋 원칙과 12주 추세가 구독 유지에 충분한 가치인지 검증할 것.
