## 1. 제품 정의

코인미러는 거래소의 과거 거래 데이터를 바탕으로 사용자의 반복적인 투자 행동을 보여주는 **투자 습관 회고 도구**다. 미래 가격, 매수·매도 시점, 포트폴리오 비중을 추천하지 않는다.

### 핵심 가치

1. 사용자가 생각하는 자신의 투자 성향과 실제 거래 기록을 비교한다.
2. 추격매수, 손실 지연, 물타기, 복구매수, 과매매, 새벽거래, 집중 매수 등의 행동을 자동 산출한다.
3. 투자거울 타입을 첫 화면의 주역으로 보여주고, F1~F10 점수는 타입 판정의 근거로 후퇴시켜 첫 사용자가 한눈에 이해하도록 돕는다.
4. 점수 자체보다 지난 분석 대비 변화와 근거 거래를 보여준다.
5. 목표와 원칙은 사용자가 고르고, 서비스는 다음 데이터에서 준수 여부를 자동 대조한다.

### 비목표

- 실시간 시세·차트·호가창 중심의 트레이딩 도구
- 투자 추천, 가격 예측, 자동 주문·출금
- 지속적인 감정 태그·목표가·손절가 입력을 강제하는 일기 앱
- 수익률 경쟁, 사용자 랭킹, 수익 개선 보장

## 2. 확정된 제품 원칙

| 영역        | 현재 결정                                                                                                                                                                                  |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 핵심 루프   | 서비스 가치 설명 → 온보딩 설문 1회(+선택 MBTI) → **예상 투자거울 타입 카드** → CSV 업로드/샘플 체험 → **기록된 타입 + 예상과의 갭** → 근거 점수 확인 → 원칙 선택 → 다음 분석에서 변화 확인 |
| 입력 마찰   | 반복 수동 입력 없이 핵심 가치가 동작해야 한다. 수동 기록은 선택 기능이며 기본 스코어의 필수 입력이 아니다.                                                                                 |
| 스코어 방향 | 모든 고객 노출 점수는 0~100점이며 **높을수록 절제·규율 상태가 양호**하다.                                                                                                                  |
| 설문 역할   | 스코어를 임의 조정하지 않는다. 해석 우선순위, 사용자 선언 기준, 예상 vs 실제 비교에 사용한다.                                                                                              |
| 데이터      | MVP는 **CSV-First 확정**. PDF 논의는 종결하고 검증 후 지원 항목으로 유지한다. Read-Only 거래소 API는 후속 핵심 확장.                                                                       |
| 저장        | 원본 거래 데이터는 기기/분석 세션 중심의 Local-First. 이메일 리포트 발송을 위해 서버에는 점수·타입·밴드 등 **최소 집계만** 보관하고 원본 거래내역은 올리지 않는다.                         |
| 요금제      | Free + 구독관리 2개. PDF 리포트는 별도 일회성 상품이 아니라 구독관리 가치에 포함한다.                                                                                                      |
| 운영        | Batch-First = 서버 주간 배치 + 이메일 리포트 발송. 실시간 매매 개입·웹소켓 상시 감시는 범위 밖이다.                                                                                        |
| 채널        | 기본 리포트 채널은 이메일. 리포트 메일과 마케팅 메일은 처음부터 동의·해지를 분리한다. 텔레그램은 후속 옵션이다.                                                                            |
| 컨테이너    | **웹 우선**. Expo는 폐기하지 않고 `npm run web` 타겟을 1순위로 하며, 네이티브 앱은 후속 검증 뒤 도입한다.                                                                                  |

## 3. 사용자와 문제

### 핵심 사용자

- 급등 추격, 손실 장기보유, 물타기, 손실 후 재진입을 반복하지만 스스로 빈도를 모르는 투자자
- 자신의 거래 횟수·시간대·승률을 실제보다 다르게 인식하는 투자자
- 평소 성격/자기이해와 실제 거래 기록에 나타난 행동 성향의 차이를 보고 싶은 투자자
- 복잡한 매매일지는 쓰지 않지만 거래소 데이터로 습관을 확인하고 싶은 투자자
- 한두 가지 원칙을 정해 장기 변화를 관리하고 싶은 투자자

### 해결할 문제

- 기억에 의존한 회고는 실제 거래 기록과 다를 수 있다.
- 거래소 화면은 손익은 보여주지만 행동 패턴은 설명하지 않는다.
- 반복 기록형 서비스는 입력 마찰 때문에 이탈하기 쉽다.
- 많은 점수보다 “내가 예상한 나와 기록된 나의 차이”가 더 빠른 아하모먼트를 만든다.

## 4. 초기 이용 흐름

### 4.1 온보딩/데모 6단계

1. **소개** — 서비스 가치와 투자 조언이 아니라는 경계 설명
2. **성향 진단** — 「내 투자 거울 설정」 객관식 설문
3. **예상 타입·거래내역** — 설문만으로 예상 투자거울 타입 카드를 먼저 보여주고 샘플 데이터 또는 CSV 업로드로 유도
4. **스코어·분석** — 기록된 투자거울 타입, 예상 타입과의 갭, 행동 스코어, 근거 거래
5. **목표·진행** — 프리셋 원칙 선택과 자동 대조
6. **정보·이벤트** — 보유/거래 종목의 사실 정보와 공식 공지

현재 `docs/coinmirror_demo.html`과 Expo 목업은 이 순차 흐름을 검증한다. 제품 진입 후 장기 IA는 아래 4개 영역으로 정리한다.

### 4.2 장기 웹 IA

```text
[홈] [분석] [원칙] [설정]
```

- **홈**: 투자거울 타입, 가장 큰 변화, 다음 확인 시점
- **분석**: 기록된 타입, 예상 vs 실제, Free 스코어, 근거 거래
- **원칙**: 프리셋 원칙, 진행률, 스트릭, 구독 리포트
- **설정**: 데이터 가져오기/삭제/내보내기, 설문 수정, 구독 관리, 고지

순차 온보딩과 장기 앱 IA는 서로 대체 관계가 아니다.

## 5. 온보딩 설문

설문 상세와 데이터 모델은 [v5.0 Product Spec §2](product-specs/v5.0_score-system-and-onboarding-survey.md)를 따른다.

### 구조

- 블록 A: 해석 기준 4문항
- 블록 B: 내 예상 4문항
- 전부 버튼 선택, 각 문항 `나중에 답하기` 허용
- 업로드를 막는 필수 관문으로 사용하지 않는다.

### 핵심 결과

- 카드 우선순위와 사용자 선언 기준 설정
- 업로드 전 「예상 타입」 카드 노출, 업로드 후 「기록된 타입」과의 갭 표시
- 업로드 후 「예상 vs 실제」 카드 최대 4개 노출
- 선택 입력한 일반 MBTI와 거래 기록 기반 투자 성향 타입 비교
- 설문 답변으로 실제 거래 기반 점수를 직접 가감하지 않는다.

## 6. 스코어 시스템

### 6.1 Free: 행동 스코어 9종 + 종합 1종

| ID  | 이름               |
| --- | ------------------ |
| F1  | 손절 습관 점수     |
| F2  | 익절 습관 점수     |
| F3  | 추격매수 점수      |
| F4  | 물타기 점수        |
| F5  | 복구매수 점수      |
| F6  | 과매매 점수        |
| F7  | 새벽거래 점수      |
| F8  | 몰빵 점수          |
| F9  | 본전 탈출 점수     |
| F10 | 투자 체력 종합점수 |

### 6.2 구독관리: 관리·추세 스코어 7종

- 습관 변화 그래프
- 회복탄력성 지수
- 하락장 적응력
- 또래 거울
- 자기인식 갭
- 운·규율 분해
- 원칙 지키기

### 표시 규칙

- `80~100 안정`, `55~79 관찰`, `0~54 주의`
- 표본 부족은 0점이 아니라 `측정 중`
- 근거 거래와 최소 표본을 함께 노출
- 점수와 수익률을 같은 대표 카드에 배치하지 않는다.
- 현재 데모의 M1~M6 및 위험도형 방향은 이전 프로토타입 표현이며, v5.0 기준으로 교체해야 한다.

### 6.3 투자 성향 타입 레이어

[v5.1 투자 성향 타입 레이어](product-specs/v5.1_investment-type-layer.md)를 따른다.

- 첫 분석 화면의 주역이며, F1~F10은 타입 판정의 근거로 확인한다.
- 설문 직후 CSV 전 예상 타입을 보여주고, 업로드 후 거래 기록 기반 기록된 타입을 보여준다.
- 사용자는 선택적으로 일반 MBTI를 입력할 수 있다.
- 일반 MBTI는 점수/타입 계산에 사용하지 않고, 자기인식 비교 문구에만 사용한다.
- 외부 노출명은 “투자 MBTI”보다 “투자 성향 타입” 또는 “투자거울 타입”을 우선한다.

## 7. 데이터 가져오기와 처리

### MVP

1. 업비트 KRW 거래내역 CSV
2. 샘플 데이터
3. 주문 병합 및 FIFO 라운드트립 재구성
4. 파싱 미리보기와 오류 행 표시
5. 원본 로컬 저장 또는 세션 내 분석

### 후속

- 바이낸스 CSV
- Read-Only 거래소 API 동기화
- PDF 텍스트형 거래내역서 PoC
- 사용자가 명시적으로 동의한 익명 집계 기반 또래 거울

### 원칙

- 주문/출금 권한은 요청하지 않는다.
- API 장애 시 CSV 경로는 항상 유지한다.
- 외부 시세 데이터가 없어도 Free 핵심 스코어가 계산되어야 한다.

## 8. Free / 구독관리

| 구분            | Free                             | 구독관리                                     |
| --------------- | -------------------------------- | -------------------------------------------- |
| 온보딩 설문     | 전체                             | 답변 변화 추적                               |
| 데이터 가져오기 | CSV·샘플                         | 반복 동기화·장기 보관 확장                   |
| 스코어          | F1~F10                           | P1~P7 및 장기 추세                           |
| 투자 성향 타입  | 첫 분석 타입 카드·선택 MBTI 비교 | 타입 변화 추적, 타입별 PDF 리포트, 원칙 추천 |
| 리포트          | 기본 분석·예상 vs 실제           | 주간/월간 추세, PDF 리포트                   |
| 원칙            | 기본 프리셋 1개                  | 최대 2개, 진척·스트릭·변화 추적              |
| 종목 정보       | 기본 사실 정보                   | 보유/관심 종목 뉴스·공식 이벤트 모아보기     |

구독 전환은 기본 분석 가치를 먼저 경험한 뒤 장기 변화 관리가 필요해지는 시점에 노출한다.

## 9. 컴플라이언스

> 본 서비스는 과거 거래 데이터를 기반으로 투자 습관을 요약하는 회고 도구입니다. 특정 가상자산의 매수·매도 추천, 가격 예측, 투자 자문, 원금 또는 수익 보장을 제공하지 않습니다.

- 지금 사세요/팔아야 합니다.

허용:

- 기록된 거래 기준으로
- 과거 행동 패턴상

## 11. 성공 지표

- 가치 설명 → 설문 시작률
- 설문 시작 → 업로드 진행률
- 예상 타입 완료율
- 예상 타입 공유/저장 클릭률
- 예상 타입 공유 → CSV 업로드 전환율
- CSV 파싱 성공률
- 첫 분석 완료율
- 예상 vs 실제 카드 확인률
- 4주 내 재분석률
- Free → 구독관리 전환율
- 원칙 4주 유지율

수익률 개선은 제품 성공 지표로 사용하지 않는다.
