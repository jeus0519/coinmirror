## 목표

투자거울 타입이 첫 화면의 주역이 되도록, 외부 시세 데이터 없이 산출 가능한 F1/F3/F6/F8과 전처리 엔진을 먼저 구현한다.

## 범위

1. 합성 픽스처 3종: 추격형 전형, 손절 못 하는 전형, 정상 거래
2. Order 30분 병합
3. 종목별 FIFO RoundTrip
4. F1 손절 습관, F3 추격매수, F6 과매매, F8 몰빵
5. 투자거울 타입 4축 연결
6. 표본 미달 시 `측정 중` / 타입 축 `?` 처리
7. 모든 상수는 `src/lib/score-engine/score-constants.ts`에 격리
