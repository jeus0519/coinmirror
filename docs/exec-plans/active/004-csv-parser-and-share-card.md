## 목표

CSV 업로드가 파일명 목업이 아니라 실제 파일 내용 기반으로 `parseCsv` → Phase 1 score-engine → 투자거울 타입까지 이어지게 한다. 동시에 예상/기록 타입 공유 카드를 점수·금액·수익률·종목명 없이 캡처 가능한 UI로 제공한다.

## 완료 기준

- [x] 업비트 KRW 추정 CSV 어댑터가 선언형 매핑 테이블로 구현됐다.
- [x] 범용 CSV 파서가 따옴표·개행·주석/빈 행·UTF-8·EUC-KR/CP949·BOM을 처리한다.
- [x] 헤더 미인식/필수 컬럼 누락은 명시적 실패로 반환한다.
- [x] 행 단위 오류는 점수에서 제외하고 `errors`에 수집한다.
- [x] 합성 정상/오류 CSV 픽스처에 `⚠️ 추정 스키마` 고지가 있다.
- [x] CSV 분석 결과가 F1/F3/F6/F8과 투자거울 타입을 만든다.
- [x] 업로드 화면에 파싱 미리보기와 계속/다시 올리기 선택이 있다.
- [x] 샘플 경로(`mock-metrics`)와 CSV 경로(`csvAnalysis`)가 상태상 분리됐다.
- [x] 예상 타입·기록된 타입 양쪽에 캡처용 공유 카드가 있다.
- [x] 공유 카드 빌더는 점수·금액·수익률·종목명을 포함하지 않는지 테스트한다.

## 남은 후속 과제

1. 실제 업비트 CSV 샘플을 확보해 `adapters/upbit.ts` 후보 헤더와 날짜/숫자 포맷을 검증한다.
2. F2/F4/F5/F7/F9/F10을 실제 CSV 기반으로 확장한다.
3. 이메일 리포트용 최소 집계 스키마를 설계한다.
4. 공유 카드 이미지 저장/내보내기와 OG/딥링크는 별도 범위로 검증한다.
