# 001 — 매매 회고 기록 (Trade Journal)

상태: ⚠️ 낡음 — 4탭 구조 기준으로 작성된 1차 스펙. 현재 앱은 `docs/coinmirror_demo.html` 기준 4단계 스테퍼로 전환됐고, 1차 진입점은 CSV 업로드/샘플체험이며 수동 입력은 보조 경로(`src/app/entry/new.tsx`)로 남아 있음. 최신 상태는 `docs/exec-plans/active/001-coinmirror-mvp-stepper-mockup.md` 참고. 이 문서는 다음 작업 때 갱신하거나 대체할 것.

## 문제

투자자는 매매 직후의 감정과 판단 근거를 빠르게 잊는다. 나중에 복기하려 해도 기억이 왜곡되어 있다.

## 목표

매매 후 30초 내에 코인/감정/메모를 기록할 수 있는 화면 하나.

## 범위 (MVP)

- 기록 추가 (코인 심볼, 감정 태그, 짧은 메모)
- 기록 목록 조회 (최신순)
- 로컬 상태(Zustand)까지만 — Supabase 영속화는 다음 스펙

## 비범위

- 감정 통계/패턴 분석 (다음 스펙)
- 수정/삭제 UI (필요해지면 추가)

## 관련 코드

- 스토어: `src/stores/use-journal-store.ts`
- 화면: 아직 없음 — `/new_screen`으로 생성 예정

## 열린 질문

- 감정 태그를 사전 정의 목록(공포/탐욕/FOMO/확신/중립)으로 고정할지, 자유 입력을 허용할지 → 우선 고정 목록으로 시작, 사용자 피드백 보고 결정
