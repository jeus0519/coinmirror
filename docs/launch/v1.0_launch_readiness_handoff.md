## 1. 이번 완료 범위

### 분석 정확도

- 매수 수수료를 FIFO 진입 원가와 `pnlPct` 분모에 포함했다.
- 부분 청산 시 매수 수수료를 소비 수량에 비례 배분하고 잔여 로트에 남은 수수료를 보존한다.
- 타 종목 체결이 사이에 있어도 같은 종목·방향의 30분 내 연속 체결을 같은 주문으로 병합한다.
- 업비트 CSV의 빈 필수 숫자, 0/음수 가격·수량, 음수 수수료, 존재하지 않는 날짜·시간을 거부한다.
- CSV parser와 업비트 adapter의 순환 의존을 제거했다.

### 지표 설명 정합성

- F3는 시장 급등이 아니라 **90일 이내 같은 종목의 내 직전 거래가 대비 높은 매수**만 측정한다.
- F8은 현재 포트폴리오가 아니라 **분석 기간 전체 매수금액 중 한 종목의 매수금액 비중**을 측정한다.
- 런타임, mock, AI 코칭, 투자거울 타입, 목표, 제품·사업·스코어 문서를 같은 의미로 정렬했다.

### AI 안전 경계

- 요청 최상위·중첩 필드, MBTI, metric ID, score band/bucket을 allowlist로 검증한다.
- 검증 후 입력 객체를 그대로 사용하지 않고 허용된 값만 새 객체로 재구성한다.
- metric `displayName`은 caller 값을 무시하고 서버의 신뢰된 ID 매핑으로 복원한다.
- raw text를 읽은 뒤 UTF-8 byte 기준 2,048-byte 제한을 적용한다.
- malformed JSON, HTTP 오류, 비정상 JSON/schema, timeout, network failure를 구분한다.
- `AbortController` 기반 3,500ms 클라이언트 timeout을 적용한다.
- 서버 `source=fallback` 결과를 AI 생성 문장처럼 표시하지 않고 로컬 기본 행동코칭으로 전환한다.
- AI는 행동 회고만 제공하며 종목 추천·가격 예측·매수/매도 지시를 허용하지 않는다.

### PDF 비밀번호 보호

- 브라우저 prompt 대신 화면 내 secure input을 사용한다.
- `secureTextEntry`, `autoComplete="off"`, `textContentType="none"`, 자동 교정·대문자화를 비활성화한다.
- 분석 성공·취소·파일 변경·오류 경로에서 비밀번호 상태를 초기화한다.
- GA4에는 일반화된 성공/실패 코드만 보내며 비밀번호·파일명·거래 원문을 보내지 않는다.

### Expo API 배포 계약

- `app.json`을 `web.output: "server"`로 정렬했다.
- `src/app/api/ai-reflection+api.ts`에서 기존 검증 handler를 재사용한다.
- Expo server export에서 `/api/ai-reflection` API route 생성을 확인했다.
- 서버 전용 변수명은 `COINMIRROR_AI_REFLECTION_OPENAI_API_KEY`이며 `EXPO_PUBLIC_*` AI secret 사용을 금지한다.

## 3. 런칭 마케팅 결정

### Primary ICP

- 최근 1~3개월 업비트에서 반복 매수·매도 기록이 있는 사용자
- 자신의 거래 빈도·재진입·손실 보유 습관을 실제 기록으로 확인하려는 사용자
- 업비트 원본 PDF를 직접 확보할 의향이 있는 사용자
- 종목 추천보다 개인정보 보호와 기록 회고를 중요하게 보는 사용자

CSV는 검증된 보조 입력으로 지원하되, 첫 획득 안내와 마케팅 메시지는 원본 PDF를 기본으로 한다.

### 메시지

> 내가 기억한 투자 습관, 실제 거래 기록과 같을까요?

> 업비트 원본 PDF를 브라우저에서 분석해 내 예상과 실제 기록의 차이를 보여드려요. 검증된 CSV도 사용할 수 있습니다. 원본 파일은 장기 저장하지 않으며 매수·매도를 추천하지 않습니다.

### 운영 판단

- D+7: 파일 확보·업로드·결과 이해·투자 조언 오인·지원시간으로 다음 제한 초대 여부 판단
- D+30 전후: 실제 다음 기간 재분석률로 반복 가치 판단
- 5~10명의 관찰형 소프트 런칭 전에는 커뮤니티 확장과 유료 광고를 하지 않는다.
- 실제 재분석 검증 전에는 구독 기능 확대를 하지 않는다.

## 5. 알려진 비차단 리스크

- 실제 업비트 CSV 원본 샘플에 대한 최종 서식 검증은 남아 있다.
- 6자리 고정 반올림은 현재 업비트 KRW 범위에는 차단 근거가 없으나 해외 거래소·초저가 자산 확장 전에 정밀도 정책을 재검토한다.
- 앱 수준 2,048-byte 제한은 edge 단계의 streaming body limit과 rate limit을 대체하지 않는다.
- 실제 fallback 비율, AI 지연, timeout 비율은 Preview와 제한 트래픽 전에는 알 수 없다.
- 다음 기간 재분석률은 시간 경과와 실제 참여자 없이는 검증할 수 없다.

## 6. 권장 실행 순서

1. 검증된 현재 변경을 단일 로컬 커밋으로 보존한다.
2. EAS Preview 배포 범위·비용·secret 등록을 승인한다.
3. `v1.0_eas_hosting_deployment_runbook.md` 순서로 합성 요청과 로그를 검증한다.
4. 실제 업비트 화면에서 파일 발급 경로를 확인하고 1페이지 획득 안내를 확정한다.
5. `v1.0_launch_marketing_playbook.md`로 P01~P03 관찰 세션을 먼저 실행한다.
6. P0/P1만 수정한 뒤 P04~P10으로 제한 확장한다.
7. D+7 단기 운영 판단을 내리고, 실제 반복 가치는 D+30 전후에 별도 판단한다.
8. 반복 가치가 확인된 뒤에만 커뮤니티 공개 범위와 구독 기능을 결정한다.
