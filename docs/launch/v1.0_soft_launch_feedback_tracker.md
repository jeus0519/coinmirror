# v1.0 코인미러 소프트 런칭 피드백 트래커

- **목적:** 무료 공개 전 5~10명의 실제 사용 행동을 기록하고, 공개 범위 확대 여부를 판단한다.
- **개인정보 원칙:** 이름, 이메일, 전화번호, 계정 ID, 종목, 금액, 수량, 수익률, 원본 파일명은 기록하지 않는다. 참여자는 `P01` 같은 임의 코드만 사용한다.
- **운영 원칙:** 말로 표현한 의향보다 실제 파일 확보·업로드·결과 설명·재분석 행동을 우선한다.

## 3. 관찰 인터뷰 스크립트

### 시작 전

1. 첫 화면만 보고 이 서비스가 무엇을 하는지 말해주세요.
2. 어디까지 데이터가 전송되거나 저장된다고 생각하나요?
3. 평소 최근 거래내역을 내려받아 본 적이 있나요?

### 과업

> “최근 업비트 거래내역으로 본인의 거래 습관을 확인해보세요. 막히면 바로 질문하기보다 지금 무엇을 찾고 있는지 소리 내어 말해주세요.”

관찰자는 파일·비밀번호·거래 원문을 보거나 받아 적지 않는다. 화면 공유 시 민감정보가 나타나면 공유를 즉시 중단하고 사용자가 직접 조작하게 한다.

### 결과 도달 후

1. 새롭게 알게 된 행동 한 가지를 본인 말로 설명해주세요.
2. 가장 믿기 어려운 지표는 무엇이며 왜 그런가요?
3. 이 결과가 매수·매도 추천이라고 느껴진 부분이 있었나요?
4. 다음 달 다시 확인한다면 어떤 질문을 확인하고 싶나요?
5. 월간 비교, 목표 추적, PDF 리포트 중 실제로 다시 올 이유가 되는 것은 무엇인가요?
6. 다른 사람에게 설명한다면 누구에게 어떤 서비스라고 말하겠나요?

**금지 질문:** “구독할 건가요?”만 단독으로 묻지 않는다. 실제 재사용 상황·필요 기능·다음 파일 업로드 의사를 먼저 확인한다.

### 초기 운영 기준

- **Green:** 무도움 업로드 70% 이상, 가치 발견 60% 이상, 투자추천 오인 0명, 지원시간 중앙값 10분 이하.
- **Yellow:** 업로드 40~69% 또는 가치 발견 30~59%. 타 거래소/유료 기능보다 해당 마찰만 수정.

## 6. 이슈 처리 규칙

| 심각도 | 예시 | 대응 |
| --- | --- | --- |
| P0 | 손익 방향 오류, 민감정보 외부 전송, 잘못된 파일을 성공 처리 | 신규 초대 중단, 재현 테스트 후 수정 |
| P1 | 지원 서식 파싱 실패, 결과 설명의 중대한 오인 | 제한 공개 유지, 24시간 내 원인 분류 |
| P2 | 카피 혼동, 버튼 위치, 추가 기능 요청 | 주간 검토 backlog |

- 원본 파일 전달을 요청하지 않는다.
- 재현이 불가피하면 사용자가 직접 제거·치환한 최소 구조 샘플만 받는다.
- 치명 결함 수정 전에는 채널 범위를 확대하지 않는다.
