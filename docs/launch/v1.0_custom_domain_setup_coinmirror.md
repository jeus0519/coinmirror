## 3. Canonical redirect 정책

- `www.coinmirror.kr`를 primary/canonical로 사용한다.
- `coinmirror.kr`, `coinmirror.co.kr`, `www.coinmirror.co.kr`는 모두 `https://www.coinmirror.kr/`로 redirect한다.
- Redirect는 app UI 로직이 아니라 Vercel project-level routing/custom domain alias 기준으로 검증한다.
- URL query/hash에는 테스트 파라미터나 민감값이 포함될 수 있으므로 공유/문서에는 canonical root만 사용한다.

검증된 redirect 결과:

```text
https://coinmirror.kr/        -> https://www.coinmirror.kr/
https://coinmirror.co.kr/     -> https://www.coinmirror.kr/
https://www.coinmirror.co.kr/ -> https://www.coinmirror.kr/
```

## 4. 공유 미리보기 상태

Production 기준 OG/Twitter 메타 적용 완료.

| 항목 | 값 |
| --- | --- |
| `title` / `og:title` / `twitter:title` | `코인미러 | 거래 기록으로 보는 나의 투자 습관` |
| `description` / `og:description` / `twitter:description` | `스코어 기반 성향 진단과 AI 행동 코칭으로 내 투자 습관을 질문으로 돌아봅니다.` |
| `og:image` / `twitter:image` | `https://www.coinmirror.kr/og/coinmirror-og.png` |
| 이미지 규격 | `1200 × 630 PNG` |

최종 OG 이미지 파일:

```text
public/og/coinmirror-og.png
```

이미지 내 문구:

```text
코인미러    AI 행동 코칭

거래 기록으로 보는
나의 투자 습관

스코어 기반 성향 진단과 AI 행동 코칭
```

공개 검증 결과:

```text
GET https://www.coinmirror.kr/
HTTP 200
Vercel login 보호 없음
새 title/description/og:image/twitter:image 반영 확인

GET https://www.coinmirror.kr/og/coinmirror-og.png
HTTP 200
content-type: image/png
width=1200
height=630
```

플랫폼 캐시 확인용 임시 URL:

```text
https://www.coinmirror.kr/?v=og-20261002
```

> 카카오톡·텔레그램·슬랙·X/Twitter는 미리보기 캐시를 가질 수 있다. 캐시가 오래 남으면 query 버전 URL로 테스트하고, 공개 발송은 canonical root를 사용한다.

## 5. Production AI 상태

Production 환경변수 이름 기준:

```text
COINMIRROR_AI_REFLECTION_OPENAI_API_KEY=*** / Secret / Production
COINMIRROR_AI_REFLECTION_MODEL=gpt-6-luna / Config / Production
```

Secret 값은 Vercel UI/서버 환경에만 보관하며 문서·Git·채팅에 저장하지 않는다.

Production smoke 결과:

```text
POST https://www.coinmirror.kr/api/ai-reflection
HTTP 200
ok=True
source=ai
errorCode=None
output_fields=nextQuestion,observedPattern,reduceAction,reinforceAction
```

AI 행동코칭은 투자 조언, 종목 추천, 가격 전망, 수익 보장, 포트폴리오 제안을 하지 않는다. 원본 거래내역·PDF 비밀번호·개별 체결 원문·종목·금액·수량·가격·계좌정보를 AI로 전송하지 않는다.

## 6. 배포·검증 절차

### Preview 검증

```bash
git push origin HEAD:main
npx --yes vercel ls coinmirror --scope data-grida
npx --yes vercel inspect <preview-url> --scope data-grida --wait --timeout 10m
```

Preview는 Deployment Protection이 적용되어 익명 접근이 Vercel login으로 이동할 수 있다. 앱 콘텐츠 검증은 인증된 `vercel curl` 또는 제한 공유 링크로 수행한다.

### Production 반영

Production 반영은 별도 승인 후 진행한다.

```bash
git push origin HEAD:production
npx --yes vercel inspect <production-url> --scope data-grida --wait --timeout 10m
npx --yes vercel inspect https://www.coinmirror.kr --scope data-grida
```

### 공개 도메인 smoke

```bash
curl -I https://www.coinmirror.kr/
curl -I https://www.coinmirror.kr/og/coinmirror-og.png
curl -L -I https://coinmirror.kr/
curl -L -I https://coinmirror.co.kr/
curl -L -I https://www.coinmirror.co.kr/
```

기대 결과:

- `www.coinmirror.kr` root: HTTP 200, Vercel login 보호 없음
- OG 이미지: HTTP 200, `image/png`, `1200x630`
- 비-primary 도메인: `www.coinmirror.kr`로 redirect 후 HTTP 200
- `/api/ai-reflection`: safe payload에서 `source=ai`
