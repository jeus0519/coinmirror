# v1.0 코인미러 P01~P03 파일럿 세션 키트

- **목적:** 첫 3명의 제한 참여자로 파일 확보·업로드·결과 이해·안전성의 치명적 마찰을 확인한다.
- **대상:** 최근 업비트 거래 경험이 있고, 본인이 직접 PDF/CSV를 내려받아 테스트할 의향이 있는 참여자.
- **예상 시간:** 15~20분.
- **운영 순서:** `P01 단독 관찰 → P0/P1 검토 → P02 → 검토 → P03`.
- **기록 위치:** `docs/launch/v1.0_soft_launch_feedback_tracker.md`.
- **상위 운영 기준:** `docs/launch/v1.0_launch_marketing_playbook.md`.

> [!IMPORTANT]
> 이름, 이메일, 전화번호, 계정 ID, 종목, 금액, 수량, 수익률, 원본 파일명, PDF 비밀번호를 이 문서·트래커·채팅 로그에 기록하지 않는다. 참여자는 `P01`, `P02`, `P03` 코드로만 관리한다.

## 1. 현재 테스트 환경

- 배포 환경: Vercel **Production / custom domain**
- 공식 URL: `https://www.coinmirror.kr`
- 접근 방식: 공개 URL. Vercel Preview protection-bypass 링크를 사용하지 않는다.
- 배포 기준 커밋: `ee3d3f9 feat: add social preview metadata`
- Production deployment: `dpl_BeoGo1YU4CYAzbxDr91HAMbDQR9j`
- 공식 지원 범위: 업비트 PDF/CSV
- 원본 처리: 브라우저 우선 처리, 원본 파일 장기 저장 안 함
- 분석 목적: 과거 거래 행동 회고. 종목 추천·가격 전망·매수/매도 지시 아님
- 공유 미리보기: OG/Twitter 이미지 적용 완료. 플랫폼 캐시 확인용으로만 `https://www.coinmirror.kr/?v=og-20261002`를 사용할 수 있다.

### 공개 링크 취급

- 아래 문안의 테스트 링크는 `https://www.coinmirror.kr`를 사용한다.
- `coinmirror.kr`, `coinmirror.co.kr`, `www.coinmirror.co.kr`는 canonical인 `www.coinmirror.kr`로 redirect된다.
- URL query에는 테스트 파라미터나 민감값을 붙이지 않는다. 캐시 확인용 query는 운영자 테스트에만 사용한다.
- 공개 URL이라도 참여자는 한 번에 1명씩 초대하고, P0/P1 검토 후 다음 참여자에게 보낸다.

## 2. 참여자 선별 메시지

> 최근 업비트 거래내역을 바탕으로 내 거래 습관을 돌아보는 무료 도구를 테스트하고 있어요. 종목 추천이나 수익률 평가는 하지 않고, 원본 파일은 브라우저에서 처리하며 장기 저장하지 않습니다.
>
> 최근 거래가 있고 업비트 PDF 또는 CSV를 직접 내려받아 15~20분 정도 도움 없이 사용해볼 의향이 있으실까요? 테스트 중 민감한 파일이나 화면을 저에게 보내실 필요는 없습니다.

### 참여 적합 기준

- [ ] 최근 1~3개월 내 업비트 거래 경험이 있다.
- [ ] 본인이 직접 거래내역 PDF 또는 CSV를 내려받을 수 있다.
- [ ] 투자 추천이 아닌 거래 습관 회고 목적을 이해한다.
- [ ] 15~20분 테스트와 짧은 후속 질문에 응할 수 있다.
- [ ] 원본 파일을 운영자에게 보내지 않는 방식에 동의한다.

하나라도 충족하지 않으면 억지로 참여시키지 않고 `후보 보류`로 둔다.

## 4. 세션 직전 운영자 체크리스트

### 환경

- [ ] 공식 URL `https://www.coinmirror.kr`가 시크릿/로그아웃 브라우저에서 코인미러 화면을 연다.
- [ ] 카카오톡/텔레그램/슬랙 등 공유 미리보기에서 최신 OG 이미지와 문구가 표시된다. 캐시 확인이 필요하면 운영자만 `?v=og-20261002`를 사용한다.
- [ ] 모바일과 PC 중 참여자가 사용할 환경을 `mobile` 또는 `desktop`으로만 기록한다.
- [ ] Tally 피드백 폼이 열리고 로그인·이메일·파일 첨부를 요구하지 않는다.
- [ ] 테스트 중 녹화·스크린샷·원본 파일 수집을 하지 않는다.

### 관찰 준비

- [ ] `v1.0_soft_launch_feedback_tracker.md`에서 해당 참여 코드 행을 준비한다.
- [ ] 지원시간 측정용 타이머를 준비한다.
- [ ] 운영자는 먼저 사용법을 설명하지 않고 첫 화면의 이해를 관찰한다.
- [ ] 질문은 유도하지 않고 “지금 무엇을 찾고 있나요?”를 우선 사용한다.
- [ ] 민감정보가 화면 공유에 나타나면 즉시 공유를 중단하고 참여자가 직접 조작하게 한다.

## 5. 15~20분 관찰 진행표

| 구간 | 시간 | 참여자 과업 | 운영자 관찰 |
| --- | ---: | --- | --- |
| 시작 | 0~2분 | 첫 화면만 보고 서비스 설명 | 대상·가치 이해, 개인정보 처리 예상 |
| 파일 확보 | 2~7분 | 업비트 PDF/CSV 찾기 | 도움 없는 확보 여부, `FILE-01/02` |
| 업로드 | 7~10분 | 파일 선택·파싱·분석 진행 | 신뢰 불안, 파싱 실패, 오류 문구 |
| 결과 이해 | 10~15분 | 투자거울 타입·예상 vs 기록·행동 점수 확인 | 새 발견, 지표 불신, 추천 오인 |
| 선택 기능 | 15~17분 | AI 행동코칭·목표·정보 탭 탐색 | 클릭 여부와 이해만 기록; 사용 유도 금지 |
| 마무리 | 17~20분 | 피드백 제출 또는 구두 회고 | 다음 재분석 이유·예정 시점 |

### 운영자가 말해도 되는 최소 문장

- “지금 무엇을 찾고 있는지 말씀해 주세요.”
- “파일이나 비밀번호는 보내지 말고 직접 입력해 주세요.”
- “화면에 보이는 일반 오류 문구만 읽어 주세요.”
- “이 결과를 본인 말로 어떻게 이해했는지 알려주세요.”

### 운영자가 하면 안 되는 행동

- 파일 발급 위치를 시작부터 대신 알려주기
- 원본 PDF/CSV를 전달받기
- PDF 비밀번호를 묻거나 화면으로 보기
- 특정 종목·손익을 해석하거나 투자 조언하기
- AI 행동코칭, 피드백 CTA, 구독 혜택을 클릭하도록 유도하기
- “좋았나요?”, “유용했죠?”처럼 긍정 답변을 유도하기

## 6. 결과 도달 후 질문

아래 순서대로 묻고 핵심만 비식별로 기록한다.

1. 첫 화면만 봤을 때 어떤 서비스라고 생각했나요?
2. 파일이 어디까지 전송되거나 저장된다고 이해했나요?
3. 가장 오래 멈춘 단계는 어디였나요?
4. 새롭게 알게 된 거래 행동 한 가지를 본인 말로 설명해주세요.
5. 가장 믿기 어려운 지표나 문장은 무엇이었나요?
6. 매수·매도 추천 또는 투자 실력 평가처럼 느껴진 부분이 있었나요?
7. AI 행동코칭을 눌렀다면 무엇을 기대했고, 실제 화면은 어땠나요?
8. 다음에 거래내역을 다시 올린다면 언제, 무엇을 비교하고 싶나요?
9. 월간 비교·목표 추적·PDF 리포트 중 실제 재사용 이유가 되는 것은 무엇인가요?

> “구독할 건가요?”만 단독으로 묻지 않는다. 실제 재사용 상황과 다음 분석 시점을 먼저 확인한다.

## 8. 중단·확대 게이트

### 즉시 중단 — P0

- 손익 방향 또는 핵심 계산 오류
- 원본 파일·비밀번호·개별 체결·계좌정보의 외부 전송 또는 저장 정황
- 지원하지 않는 파일을 정상 분석으로 잘못 처리
- 공식 도메인 외 임시 테스트 URL, credential, API key, protection-bypass token 유출

**조치:** 신규 초대를 즉시 멈추고 재현 테스트와 수정이 끝날 때까지 다음 참여자에게 링크를 보내지 않는다.

### 다음 참여자 전 조치 — P1

- 최신 업비트 PDF/CSV 파싱 실패
- 파일 발급 경로를 사실상 찾을 수 없음
- 핵심 결과를 투자 추천·실력 평가로 오인
- 분석 결과의 핵심 의미를 설명할 수 없음
- 일반 오류 문구만으로 다음 행동을 알 수 없음

**조치:** 원인을 분류하고 24시간 내 수정 여부 또는 관찰 지속 사유를 기록한 뒤 다음 참여자를 진행한다.

### 묶어서 처리 — P2

- 간격·색상·문구 선호
- 부가 차트·기능 요청
- 결과 이해를 막지 않는 버튼 위치 의견

**조치:** 즉시 개발하지 않고 backlog로 모아 P03 완료 후 검토한다.

### P04~P10 확대 최소 조건

- [ ] P01~P03에서 미해결 P0가 0건이다.
- [ ] 반복 발생한 P1의 원인과 조치가 정리됐다.
- [ ] 최소 2명이 도움 없이 파일을 확보하고 결과에 도달했다.
- [ ] 투자 추천 오인이 0명이다.
- [ ] 원본 파일이나 민감정보를 운영자에게 전달받지 않았다.
