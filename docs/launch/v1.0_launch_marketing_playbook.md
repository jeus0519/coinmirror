# v1.0 코인미러 무료 공개 런칭 마케팅 플레이북

- **상태:** 소프트 런칭 실행용 초안
- **기준일:** 2026-09-09
- **연결 계획:** [`010-v1.0-analysis-trust-and-launch-marketing.md`](../exec-plans/active/010-v1.0-analysis-trust-and-launch-marketing.md)
- **목표:** 트래픽을 크게 만드는 것이 아니라, 업비트 거래내역을 직접 올리고 결과를 이해한 사용자가 다음 기간에도 재분석하는지 검증한다.

---

## 1. 런칭 전략 한 줄

> 최근 업비트 거래가 있는 사용자에게 “내가 기억한 투자 습관과 실제 기록의 차이”를 무료로 보여주고, 원본을 장기 저장하지 않는다는 신뢰를 기반으로 다음 달 재분석 행동을 확인한다.

AI는 유입 보조 표현이지 핵심 약속이 아니다. 핵심 약속은 **내 예상과 실제 기록의 차이를 확인하는 것**이다.

## 2. 초기 타겟

### Primary ICP

| 조건 | 선별 질문 | 적합 신호 |
| --- | --- | --- |
| 최근 거래 | 최근 1~3개월 업비트에서 매수·매도를 반복했나요? | 반복 거래 있음 |
| 입력 가능성 | 업비트 원본 PDF를 직접 내려받을 수 있나요? | 직접 시도 의향 있음; 검증된 CSV도 보조 입력 가능 |
| 문제 인식 | 거래 빈도·재진입·손실 보유 습관이 궁금한가요? | 특정 행동 질문이 있음 |
| 가치 기대 | 종목 추천이 없어도 기록 회고가 유용한가요? | 자기 점검 가치 인정 |
| 개인정보 태도 | 원본을 장기 저장하지 않는 방식이 중요한가요? | local-first를 신뢰 요인으로 인식 |

### 제외 대상

- 최근 거래가 거의 없는 장기 보유자
- 업비트 자료가 없는 사용자
- 매수·매도 추천, 시세 예측, 수익 보장을 기대하는 사용자
- 거래내역 파일 확보를 원하지 않는 사용자
- 실제 돈이나 종목 성과를 공개·비교하려는 사용자

초기 검증에서 제외는 시장 포기가 아니라 **신호의 노이즈를 줄이는 것**이다.

## 3. 가치 제안과 메시지 실험

### 공통 Hero

**내가 기억한 투자 습관, 실제 거래 기록과 같을까요?**

업비트 원본 PDF를 브라우저에서 분석해 내 예상과 실제 기록의 차이를 보여드려요. 검증된 CSV도 사용할 수 있습니다. 원본 파일은 장기 저장하지 않으며, 매수·매도를 추천하지 않습니다.

**CTA:** `내 기록 무료로 비춰보기`

### Message A — 발견 중심

- **Headline:** `나는 거래를 자주 안 한다고 생각했는데, 기록도 그럴까요?`
- **Body:** `내 예상과 실제 거래 빈도·보유기간·재진입 패턴의 차이를 확인해보세요.`
- **사용 채널:** 직접 초대, 사례형 콘텐츠
- **가설:** 자기인식 차이가 업로드 마찰을 이길 만큼 강한 호기심을 만든다.

### Message B — 신뢰 중심

- **Headline:** `거래내역을 맡기지 않고, 브라우저에서 확인하는 월간 투자 회고`
- **Body:** `업비트 원본 PDF를 브라우저에서 분석하고 장기 저장하지 않아요. 검증된 CSV도 지원하며, 과거 행동만 비춰봅니다.`
- **사용 채널:** 개인정보 민감도가 높은 데이터/분석 네트워크
- **가설:** local-first 설명이 파일 업로드 불안을 낮춘다.

### Message C — AI 중심은 보조로만 사용

- **Headline:** `AI가 종목을 추천하는 대신, 내 과거 행동을 질문으로 정리합니다.`
- **제한:** 첫 번째 메시지로 사용하지 않는다. AI가 원본 거래내역을 분석 서버에 저장한다고 오인할 수 있기 때문이다.

### 금지 카피

- 수익률을 높여드립니다
- 투자 실력을 진단합니다
- 급등주·추천 종목을 찾습니다
- AI가 매수·매도 시점을 알려드립니다
- 상위 투자자와 비교합니다

## 4. 채널별 실행 순서

### 1순위 — 직접 초대 5~10명

**대상:** 업비트 실거래 경험이 확인된 지인 또는 기존 전문 네트워크의 제한된 참여자.

**목적:** 메시지 반응보다 전체 과업 관찰.

**초대 문안:**

> 업비트 거래내역을 브라우저에서 분석해, 내가 예상한 거래 습관과 실제 기록의 차이를 보여주는 무료 도구를 만들고 있어요. 종목 추천이나 수익률 평가는 없고, 원본 파일은 장기 저장하지 않습니다. 최근 거래가 있고 PDF/CSV를 직접 받아 테스트해볼 의향이 있다면 15~20분 동안 도움 없이 사용해본 뒤 막힌 지점만 알려주실 수 있을까요? 민감한 파일이나 화면을 저에게 보내실 필요는 없습니다.

**후속 문안:**

> 사용 중 원본 거래내역이나 비밀번호는 보내지 말아주세요. 막힌 단계, 화면에 표시된 일반 오류 문구, 파일의 열 이름처럼 개인 거래를 드러내지 않는 정보만 알려주시면 됩니다.

### 2순위 — 창업자 보유 전문성 채널

후보:
- GA4 관련 독자·교육 네트워크
- 데이터 분석/컨설팅 동료 네트워크
- 가상자산 데이터 분석에 관심 있는 지인

**포지셔닝:** 투자상품이 아니라 `개인 금융 데이터를 브라우저에서 분석하는 제품 실험`.

**주의:** 현 직장·업무 관계에서 이해충돌 또는 영리 활동으로 오인될 수 있는 채널은 사내 규정 확인 전 사용하지 않는다. 직장 내부 데이터·고객·브랜드·직함을 홍보 근거로 사용하지 않는다.

### 3순위 — 사례형 콘텐츠

**콘텐츠 1:** `기억과 기록이 달라지는 3가지 투자 행동`

구성:
1. “나는 거래를 많이 안 한다”는 예상
2. 합성 데이터에서 확인된 실제 월평균 주문
3. 추천이 아닌 회고 질문
4. 코인미러 무료 분석 CTA

**콘텐츠 2:** `거래내역 파일을 서버에 맡기지 않고 분석한다는 것`

구성:
1. 브라우저에서 원본 분석
2. AI에는 범주화된 요약만 전달
3. 저장되는 것과 저장되지 않는 것
4. 한계: 같은 브라우저가 아니면 이전 비교가 이어지지 않을 수 있음

**콘텐츠 3:** `AI 투자 조언 대신 다음 달에 확인할 질문 만들기`

실제 손익·종목 대신 합성/익명 예시만 사용한다.

### 4순위 — 외부 커뮤니티

**진입 조건:**
- 분석 정확도·AI·배포 게이트 통과
- 직접 초대 cohort에서 P0 결함 0건
- 도움 없는 업로드 완료율 40% 이상

**게시 원칙:**
- 각 커뮤니티의 홍보·링크 규칙을 먼저 확인
- 동일 문구 대량 게시 금지
- “무료 도구 출시”보다 “내 예상과 거래 기록 차이를 확인하는 실험 참여 요청”으로 설명
- 투자 성과·수익 인증·공포 자극 금지
- 댓글에서 개인 파일 업로드를 요청하지 않음

### 5순위 — 유료 광고

실제 다음 기간 재분석률이 확인되기 전에는 집행하지 않는다. 클릭과 첫 업로드만 확인된 상태에서 광고를 늘리면 파일 확보 마찰과 운영 지원 비용만 확대될 수 있다.

## 6. 퍼널과 판단 기준

### 핵심 퍼널

```text
landing_view
→ start_click
→ diagnosis_complete
→ upload_attempt
→ parse_success | parse_failed
→ result_view
→ ai_coaching_request_click
→ reanalysis_reminder_click
→ 실제 다음 기간 reanalysis_return/comparison_result_view
```

### 우선순위

1. 도움 없이 파일 확보·업로드 완료
2. 결과에서 새 행동 한 가지를 설명
3. 투자 추천이 아님을 정확히 이해
4. 다음 기간 실제 재분석
5. 수동 지원 시간
6. 그 다음에만 구독 혜택 관심

### 초기 기준

| 지표 | Green | Yellow | Red |
| --- | ---: | ---: | ---: |
| 도움 없는 파일 확보+업로드 | 70% 이상 | 40~69% | 40% 미만 |
| 결과 가치 발견 | 60% 이상 | 30~59% | 30% 미만 |
| 투자추천 오인 | 0명 | 1명 | 2명 이상 |
| 지원시간 중앙값 | 10분 이하 | 11~20분 | 20분 초과 |
| 실제 다음 기간 재분석(D+30 전후) | 30% 이상 | 10~29% | 10% 미만 |

위 기준은 업계 벤치마크가 아니라 5~10명 소프트 런칭의 내부 운영 기준이다.

D+7 판단은 파일 확보·업로드·결과 이해·안전성까지만 사용한다. 실제 재분석 지표는 참여자가 정한 다음 분석 시점 또는 D+30 전후에 별도 확정하며, 그전에는 `미측정`으로 둔다.

## 7. 실험 해석 규칙

### Message A/B 비교

노출 수나 클릭 수만으로 승자를 정하지 않는다.

**승자 기준:**
1. 적합 사용자의 업로드 완료율
2. 결과 가치 발견률
3. 개인정보 설명 이해도
4. 지원시간

표본이 작기 때문에 통계적 유의성을 주장하지 않고, 반복해서 관찰되는 마찰과 사용자 언어를 다음 카피에 반영한다.

### 관심과 지불 의향 구분

- `AI 클릭`: 결과 안에서의 호기심
- `재분석 알림 클릭`: 후속 관심
- `선호 혜택 선택`: 기능 선호
- `실제 다음 기간 업로드`: 반복 가치의 첫 증거
- `결제`: 겸업·이해충돌 검토 후 별도 실험

알림 클릭률을 구독 전환 의향으로 보고하지 않는다.

## 8. 입력 획득 가설과 사전 확인

업비트 공식 고객센터 검색 결과에는 서비스에서 신청하는 거래내역서가 PDF 형식을 지원하고, Excel 파일은 고객센터 문의가 필요하다고 안내되어 있다. 공식 페이지는 이번 세션에서 봇 차단으로 본문을 직접 추출하지 못했으므로, **런칭 직전 실제 업비트 PC/앱 화면에서 경로와 최신 문구를 사람이 다시 확인**한다.

- 첫 안내는 즉시 발급 가능성이 높은 **업비트 PDF 중심**으로 작성한다.
- CSV는 코인미러가 읽을 수 있는 형식이더라도 모든 사용자가 즉시 받을 수 있다고 약속하지 않는다.
- 실제 발급 화면을 확인하기 전 생년월일·휴대폰번호 등 비밀번호 규칙을 추측해 안내하지 않는다.
- 도움 없는 파일 확보율을 독립 KPI로 둔다. 확보율이 낮으면 분석 기능보다 획득 안내를 먼저 고친다.

| 병목 | 조기 신호 | 대응 |
| --- | --- | --- |
| 파일 받는 법 문의 | FILE-01 반복 | 1페이지 안내 제작, UI에서 출처 범위 선명화 |
