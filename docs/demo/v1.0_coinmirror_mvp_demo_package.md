## 1. 한 문장 포지셔닝

> 코인미러는 거래소 파일 하나로 “얼마 벌었는지”가 아니라 “어떻게 거래했는지”를 비춰보는 가상자산 투자 습관 회고 서비스입니다.

### 30초 설명

코인미러는 업비트 PDF/CSV 거래내역을 브라우저에서 읽어 투자자의 반복 행동을 요약합니다. 매수·매도 추천, 가격 예측, 종목 점수는 제공하지 않습니다. 대신 청산 승률, 수익·손실 보유기간, 과매매, 몰빵 같은 행동 지표를 계산하고, 사용자가 생각한 자기 모습과 실제 기록의 차이를 보여줍니다. 첫 분석은 무료로 제공하고, 구독관리에서는 기준선을 저장해 다음 업로드와 비교하며 목표와 월간 회고 리포트까지 이어갑니다.

### 10초 버전

> 거래내역 파일 하나로 내 투자 습관을 돌아보고, 다음 업로드 때 변화까지 비교하는 회고 도구입니다.

---

## 2. 데모의 핵심 메시지

데모에서 반드시 전달해야 하는 메시지는 5개다.

1. **거래소는 손익을 보여주지만, 코인미러는 행동을 보여준다.**
2. **사용자는 매매일지를 쓰지 않아도 된다. 이미 존재하는 거래내역 파일을 사용한다.**
3. **추천하지 않는다. 매수·매도·종목·가격 예측을 하지 않는 것이 제품 정의다.**
4. **2회차부터 가치가 커진다. 기준선 저장, 중복 업로드 자동 제외, 변화 비교가 재방문 이유다.**
5. **원본 PDF, PDF 비밀번호, 개별 체결 원문은 장기 저장하지 않는다. local-first 요약 스냅샷만 쓴다.**

## 5. 상세 데모 스크립트

### 0:00~0:30 — 시작 화면

**화면:** `http://localhost:8081/`

**말할 내용:**

> 코인미러는 가상자산 투자자를 위한 거래 습관 회고 서비스입니다. 거래소는 보통 얼마를 벌고 잃었는지를 보여주지만, 코인미러는 내가 어떻게 거래했는지를 보여줍니다. 추천이나 가격 예측은 하지 않고, 이미 있는 거래내역 파일을 읽어 행동 패턴을 정리합니다.

**강조 포인트:**

- 손익/수익률 중심이 아니라 행동 회고
- 투자 조언이 아니라 자기 이해 도구
- 파일 하나로 시작

**주의:**

- “투자를 잘하게 해준다”라고 말하지 않는다.
- “수익률을 높인다”라고 말하지 않는다.

---

### 0:30~1:20 — 성향 진단/자기 예상

**화면:** 온보딩 8문항 또는 설명만 진행

**말할 내용:**

> 시작할 때 사용자가 본인을 어떻게 생각하는지 먼저 묻습니다. 예를 들어 한 달 거래 횟수, 손실 대응, 자금 배분 같은 항목입니다. 중요한 건 맞고 틀림을 평가하려는 게 아니라, 나중에 실제 거래 기록과 나란히 놓기 위해서입니다. 사람은 자기 거래 빈도나 손실 보유 시간을 꽤 다르게 기억하기 때문입니다.

**강조 포인트:**

- 설문은 성격검사가 아니라 자기 예상값
- 나중에 실제 기록과 비교하는 장치
- 미응답도 허용

---

### 1:20~2:10 — 거래내역 업로드

**화면:** `http://localhost:8081/?step=upload`

**말할 내용:**

> 매매일지 앱은 직접 기록해야 해서 가장 필요한 순간에 이탈합니다. 코인미러는 업비트에서 받은 PDF나 CSV 거래내역을 사용합니다. 사용자가 새로 적을 필요가 없습니다. 분석은 브라우저에서 처리하고, 원본 PDF와 비밀번호는 저장하지 않는 방향으로 설계했습니다.

**강조 포인트:**

- PDF/CSV 모두 지원
- 매매일지 입력 마찰 제거
- 원본/비밀번호 저장 금지

**화면에서 보여줄 것:**

- PDF 선택
- CSV 선택
- 2회차 중복 업로드 데모 버튼

---

### 2:10~3:10 — 1회 분석 결과

**화면:** 샘플 분석 또는 실제 업로드 결과

**말할 내용:**

> 분석 결과는 투자거울 타입과 행동 점수로 나뉩니다. 타입은 사용자가 기억하기 쉬운 요약이고, F점수는 그 근거입니다. 예를 들어 손절 습관, 추격매수, 과매매, 몰빵 같은 지표를 봅니다. 점수는 투자 실력이나 성과 점수가 아니라, 거래 기록에서 관찰된 행동 지표입니다.

**강조 포인트:**

- 타입 먼저, 점수는 근거
- 점수는 높을수록 행동 안정성이 좋다는 의미
- 표본이 부족하면 과장하지 않고 “측정 중”으로 표시

**주의:**

- 특정 종목이 좋다/나쁘다 말하지 않는다.
- 수익률 개선을 약속하지 않는다.

---

### 3:10~4:20 — 2회차 중복 업로드/교차 청산 데모

**화면:** `http://localhost:8081/?demo=duplicate-upload`

**말할 내용:**

> 구독관리의 핵심은 2회차부터입니다. 사용자는 다음 달 거래내역을 다시 올릴 때 이전 기간과 겹치는 파일을 올릴 수 있습니다. 그래서 코인미러는 체결 시각, 종목, 방향, 가격, 수량, 수수료를 정규화해 중복 체결을 자동 제외합니다. 단, 이전 기간에 산 매수를 이번 기간에 매도한 경우가 있습니다. 이때 과거 매수는 신규 거래로 다시 세지 않고, 원가 연결용으로만 사용해 승률과 보유기간을 보정합니다.

**화면에서 반드시 보여줄 문구:**

```text
중복 체결 자동 처리
이미 저장된 기준선과 겹치는 중복 체결 1건을 제외하고 신규 체결 3건만 비교했어요.
기간 밖 매수 1건을 원가 연결용으로만 사용했어요.
```

**쉽게 풀어 말하기:**

> 사용자가 같은 파일을 또 올려도 숫자가 부풀지 않게 막고, 과거에 산 코인을 이번에 판 경우에는 계산이 끊기지 않게 연결합니다.

**강조 포인트:**

- 사용자가 중복 여부를 직접 정리하지 않아도 됨
- 지표 왜곡 방지
- 2회차 업로드에서 구독관리 가치가 발생

---

### 4:20~5:00 — 월간 리포트와 구독관리

**화면:** 분석 화면의 월간 리포트 카드 → `/subscription`

**말할 내용:**

> 이렇게 저장된 분석 요약은 월간 투자습관 리포트로 묶입니다. MVP에서는 PDF를 바로 만들기보다, 앱 안에서 이번 달 저장한 분석, 신규 반영 체결, 중복 제외, 원가 연결 보정, 목표 회고를 먼저 보여줍니다. 구독관리는 더 많은 기능을 잠그는 방식이 아니라, 한 번 본 분석을 다음 달 변화로 이어가는 방식입니다.

**화면에서 보여줄 문구:**

```text
월간 투자습관 리포트 미리보기
이번 달 저장한 분석
신규 반영 체결
중복 제외
원가 연결 보정
목표 회고
```

**마무리 멘트:**

> 코인미러는 판단을 대신하는 서비스가 아닙니다. 사용자가 이미 남긴 거래 기록을 바탕으로 자기 행동을 돌아보게 만드는 도구입니다. 그래서 추천하지 않는 것, 원본을 오래 저장하지 않는 것, 2회차부터 변화 비교를 만드는 것이 제품의 핵심입니다.

> 코인미러는 거래소 파일 하나로 내 투자 습관을 돌아보는 서비스입니다. 매수·매도 추천이나 가격 예측은 하지 않습니다. 업비트 PDF/CSV 파일을 읽어 손절, 추격매수, 과매매, 몰빵 같은 행동 지표를 보여줍니다. 2회차부터는 이전 분석을 기준선으로 저장해 다음 업로드와 비교합니다. 사용자가 이전 기간과 겹치는 파일을 올려도 중복 체결은 자동 제외하고, 과거에 산 코인을 이번에 판 경우에는 원가 연결용으로만 보정합니다. 이렇게 쌓인 분석 요약은 월간 투자습관 리포트로 묶어, 내가 반복하는 행동이 줄어드는지 회고하게 만듭니다.

## 7. 예상 질문과 답변

### Q1. 이건 투자 조언 아닌가요?

**답변:**

아닙니다. 코인미러는 특정 종목, 가격, 매수·매도 시점을 제안하지 않습니다. 사용자의 과거 거래 기록에서 행동 지표를 계산하고, 사용자가 직접 회고할 수 있게 보여주는 서비스입니다. 그래서 제품 문구에서도 추천, 예측, 수익 보장 표현을 금지합니다.

---

### Q2. 거래소나 포트폴리오 앱과 뭐가 다른가요?

**답변:**

거래소와 포트폴리오 앱은 주로 평가금액, 손익, 수익률을 보여줍니다. 코인미러는 결과보다 행동을 봅니다. 예를 들어 손실 거래를 얼마나 오래 들고 있었는지, 매수 주문이 과도하게 많았는지, 한 종목에 매수금액이 몰렸는지를 회고 지표로 보여줍니다.

---

### Q3. 매매일지 앱과 뭐가 다른가요?

**답변:**

매매일지는 직접 적어야 합니다. 문제는 거래를 충동적으로 한 직후일수록 기록을 잘 남기지 않는다는 점입니다. 코인미러는 사용자가 이미 거래소에 남긴 기록을 사용하므로, 별도 입력 부담이 훨씬 낮습니다.

---

### Q4. 중복 업로드는 왜 중요한가요?

**답변:**

사용자는 거래내역을 기간별로 완벽하게 자르지 않고 겹치는 파일을 올릴 가능성이 큽니다. 중복 체결을 그대로 세면 주문 수, 승률, 보유기간이 왜곡됩니다. 코인미러는 체결 fingerprint로 이전 스냅샷과 겹치는 체결을 제외해 지표가 부풀지 않게 합니다.

---

### Q5. 과거 매수를 이번 매도와 연결하는 건 왜 필요한가요?

**답변:**

예를 들어 지난달에 산 코인을 이번 달에 팔 수 있습니다. 이번 달 파일만 보면 매도만 있고 원가가 없어 손익과 보유기간을 계산하기 어렵습니다. 그래서 이전에 이미 본 매수 체결은 신규 거래로 다시 세지 않고, 원가 연결용 context lot으로만 사용합니다.

---

### Q6. 원본 거래내역은 저장하나요?

**답변:**

MVP 원칙은 저장하지 않는 것입니다. 원본 PDF, PDF 비밀번호, 개별 체결 원문, 계좌 식별자는 장기 저장하지 않습니다. local-first 구독관리에서는 분석 요약 스냅샷, 목표, 중복 식별용 fingerprint 같은 제한된 파생값만 저장합니다.

---

### Q7. 왜 구독할까요?

**답변:**

한 번의 분석은 무료로 충분히 보여줍니다. 유료 구독관리는 “다음 달에도 내 행동이 반복되는지”를 보는 기능입니다. 기준선 저장, 다음 업로드 비교, 목표 추적, 월간 리포트처럼 시간이 쌓여야 가치가 생기는 영역을 구독 기능으로 둡니다.

---

### Q8. PDF 리포트는 제공하나요?

**답변:**

최종적으로는 PDF 리포트도 후보입니다. 다만 현재 MVP에서는 실제 PDF 생성보다 앱 안 월간 리포트 미리보기를 먼저 구현했습니다. 이유는 서버/로그인/결제와 연결되기 전에 사용자가 어떤 회고 가치를 느끼는지 먼저 검증하기 위해서입니다.

## 8. 금지 표현과 대체 표현

| 금지 표현 | 이유 | 대체 표현 |
| --- | --- | --- |
| 수익률을 높여줍니다 | 성과 보장처럼 들림 | 거래 행동을 회고합니다 |
| 이 종목을 피하세요 | 종목 추천/비추천 | 특정 종목 비중이 높았는지 보여줍니다 |
| 매수/매도 타이밍을 잡아줍니다 | 투자 자문 위험 | 과거 진입/청산 패턴을 보여줍니다 |
| 투자 실력을 평가합니다 | 성적표/판정 느낌 | 행동 지표를 요약합니다 |
| 상위 n% 투자자 | 검증되지 않은 비교 | 내 이전 기록과 비교합니다 |
| 다음 달 수익을 예측합니다 | 예측/보장 위험 | 다음 업로드 때 변화를 확인합니다 |
| AI가 투자 판단을 도와줍니다 | 자문 오해 | AI/알고리즘이 거래 기록을 정리합니다 |


```text
거래 성과나 투자 실력을 평가하는 점수가 아니라, 거래 기록에서 관찰된 행동 지표입니다.
```

### 기준선 비교

```text
이번 분석을 저장해두면 다음 업로드 때 승률, 보유기간, 거래 빈도 변화를 비교할 수 있어요.
```

### 중복 처리

```text
중복 체결은 제외하고 신규 체결만 비교 결과에 반영했어요.
기간 밖 매수분은 중복 집계하지 않고 신규 매도 원가 연결용으로만 사용해요.
```

### 월간 리포트

```text
이번 리포트는 이 달에 저장한 분석 요약을 기준으로 만든 회고예요.
```

### 구독 페이지

```text
한 번 본 분석을, 다음 달 변화로 이어가요.
```

## 12. 데모 후 판단 기준

### 좋은 신호

- 사용자가 “내 거래내역으로 해보고 싶다”고 말함
- 중복 업로드 자동 제외를 현실적인 문제로 이해함
- 월간 리포트보다 “다음 업로드 비교”에 먼저 반응함
- 투자 추천이 없다는 점을 오히려 신뢰 요소로 받아들임
- 파일 업로드 보안 문구를 보고 안심함

### 나쁜 신호

- 첫 화면에서 투자 추천 서비스로 오해함
- PDF/CSV 업로드 자체를 꺼림
- 월간 리포트를 “수익률 리포트”로 오해함
- 중복/원가 연결 보정 설명이 너무 어렵다고 느낌
- 구독 이유가 첫 분석만으로 충분하다고 느껴지지 않음

### 다음 의사결정

| 관찰 | 다음 액션 |
| --- | --- |
| 업로드 불안이 크다 | 보안/로컬 처리 설명 화면 강화 |
| 중복 처리 설명이 어렵다 | “같은 파일을 또 올려도 숫자가 부풀지 않아요”로 단순화 |
| 월간 리포트 반응이 좋다 | 별도 `/monthly-report` route 검토 |
| 목표 추적 반응이 좋다 | 목표 화면을 별도 스텝으로 강화 |
| 구독 CTA 반응이 낮다 | 가격/가치/무료 범위 재조정 |
