# Expo SDK 참고 메모

Expo는 버전마다 API가 자주 바뀐다. 코드를 쓰기 전에 설치된 SDK 버전의 공식 문서를 확인한다.

- 설치된 버전: `package.json`의 `expo` 값 확인 (현재 ~57.x)
- 버전별 정확한 문서: `https://docs.expo.dev/versions/v<installed-version>/`
- expo-router 문서: https://docs.expo.dev/router/introduction/
