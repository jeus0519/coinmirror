## 1. 제품 의도

투자 스코어는 필요하지만, 초보 사용자는 F1~F10 전체를 한 번에 이해하기 어렵고 낮은 점수는 손실회피를 자극해 이탈을 만들 수 있다. 투자 성향 타입은 성적표가 아니라 정체성에 가까운 언어로 “최근 거래 기록에서는 어떤 패턴이 강했는지” 보여주는 첫 분석 화면의 주역이다.

타입 4축은 `F3 < 55` 같은 이분법 판정으로 시작할 수 있어 절대 점수 눈금의 정밀도에 상대적으로 둔감하다. 따라서 v5.0 상수가 아직 미검증인 현재 단계에서 사용자에게 먼저 내놓을 수 있는 안전한 산출물은 숫자 점수보다 타입 카드다.

### 1.1 기대 효과

1. **아하모먼트 강화**: “내가 생각한 나”와 “기록된 나”의 차이를 더 직관적으로 보여준다.
2. **공유성 증가**: 점수보다 타입명이 기억과 공유에 유리하다.
3. **구독 전환 훅**: 타입 변화 추적, 타입별 PDF 리포트, 타입별 원칙 추천으로 구독관리 가치를 만든다.
4. **복잡도 완화**: F1~F10 상세 점수로 들어가기 전, 대표 성향을 먼저 제공한다.

### 1.2 비목표

- 심리검사 또는 성격검사로 포장하지 않는다.
- 특정 코인, 매수/매도 시점, 포트폴리오 비중을 추천하지 않는다.
- 일반 MBTI와 투자 성과의 인과관계를 주장하지 않는다.
- 타입을 고정 정체성처럼 표현하지 않는다. 항상 “최근 거래 기록 기준”으로 말한다.

## 2. UX 위치

### 2.1 설문 기반 「예상 타입」

CSV 업로드 전, 온보딩 8문항만으로 예상 투자거울 타입을 먼저 보여준다. 이 단계의 목적은 점수 계산이 아니라 “내가 생각한 나”를 카드화해 CSV 업로드 전 마찰을 낮추는 것이다.

축 매핑 초안:

| 축        | 설문 재료                                  | 판정 초안                     |
| --------- | ------------------------------------------ | ----------------------------- |
| 진입 방식 | A2① 오르는 코인 추격, A1 급등 진입         | 추격형(C) / 대기형(W)         |
| 거래 속도 | A1 투자 스타일, B1 예상 월 거래횟수        | 단기반응형(R) / 장기보유형(H) |
| 손실 대응 | A2② 손절 지연, B3 이익·손실 정리 속도 예상 | 손실보류형(L) / 손실정리형(X) |
| 자금 배분 | A2⑥ 몰빵 고민, A4 한 종목 한도             | 집중형(N) / 분산형(D)         |

- 미응답 축은 `?`로 둔다.
- 카드에는 반드시 **예상 타입**이라고 표기한다.
- 업로드 후 **기록된 타입**과의 갭을 첫 아하모먼트로 만든다.

```text
예상 투자거울 타입: C-R-?-N · 예상 추격형 단기 반응가
CSV 없이 만든 예상입니다. 업로드 후 기록된 타입과 나란히 비교해 드려요.
```

### 2.2 온보딩 선택 MBTI 입력

기존 v5.0 8문항 뒤 또는 설정 화면에 선택 입력을 추가한다.

```text
선택 사항 · 평소 MBTI를 알고 있다면 골라 주세요.
모르거나 입력하고 싶지 않다면 건너뛰어도 됩니다.

이 값은 투자 점수 계산에 사용하지 않고,
나중에 거래 기록 기반 투자 성향 타입과 비교하는 데만 사용합니다.
```

입력 옵션:

- 16개 MBTI 코드: `INTJ`, `INTP`, ..., `ESFP`
- `모르겠어요`
- `입력하지 않기`

### 2.3 첫 분석 결과 카드 — 기록된 타입

업로드 후 스코어 화면 최상단에 노출한다. F1~F10 상세 점수는 이 카드 아래에서 근거로 확인한다.

```text
투자거울 타입
추격형 단기 반응가

최근 거래 기록에서는 이미 오른 가격을 따라 들어간 비중과
짧은 간격의 반복 거래가 상대적으로 강하게 나타났어요.
이 타입은 성격검사가 아니라, 기록된 거래 행동을 요약한 결과예요.
```

일반 MBTI를 입력한 경우:

```text
평소 MBTI: INTP
거래 기록 기반 투자 타입: 추격형 단기 반응가

평소에는 신중하게 판단한다고 느껴도,
최근 거래 기록에서는 급등 후 빠르게 진입한 패턴이 더 자주 보였어요.
```

일반 MBTI 미입력 시:

```text
평소 MBTI를 입력하지 않아도 괜찮아요.
코인미러의 투자 타입은 거래 기록만으로 산출됩니다.
```

## 3. 타입 산출 구조

### 3.1 4축 코드

첫 버전은 4축 2분류로 시작한다. 총 16개 조합을 만들 수 있지만, 모든 조합에 별도 상세 설명을 쓰기보다 대표 축 2~3개를 조합해 자연어 타입명을 만든다.

| 축        | 코드 A        | 코드 B        | 주요 판단 데이터                                 |
| --------- | ------------- | ------------- | ------------------------------------------------ |
| 진입 방식 | C: 추격형     | W: 대기형     | F3 추격매수 점수, 급등 후 매수 비중              |
| 거래 속도 | R: 단기반응형 | H: 장기보유형 | F6 과매매 점수, 평균 보유시간, 월 주문 수        |
| 손실 대응 | L: 손실보류형 | X: 손실정리형 | F1 손절 습관 점수, 손실 보유시간, 깊은 손실 비중 |
| 자금 배분 | N: 집중형     | D: 분산형     | F8 몰빵 점수, 상위 종목 매수 집중도              |

예시 코드:

- `C-R-L-N`: 추격형 단기 반응가
- `W-H-X-D`: 분산형 장기 관찰가
- `C-H-L-N`: 집중형 물타기 방어가
- `W-R-X-D`: 분산형 짧은 점검가

### 3.2 축 판정 원칙

점수는 높을수록 양호하므로, 낮은 점수는 해당 행동 편향이 강하다는 신호로 본다.

| 축        | 판정 규칙 초안                                                               |
| --------- | ---------------------------------------------------------------------------- |
| 진입 방식 | F3 < 55 또는 추격 매수금액 비중 상위 → C, 그 외 W                            |
| 거래 속도 | F6 < 55 또는 월평균 Order 수가 자기 기준선 대비 높음 → R, 그 외 H            |
| 손실 대응 | F1 < 55 또는 손실 보유시간/이익 보유시간 비율이 높음 → L, 그 외 X            |
| 자금 배분 | F8 미측정이면 `N/D 미확정`, F8 < 55 또는 상위 1종목 집중도 과다 → N, 그 외 D |

표본 미달 시 해당 축은 `?`로 둔다.

```text
C-R-?-N
추격·단기 반응 성향은 보이지만, 손실 대응 축은 아직 손실/이익 청산 표본이 더 필요해요.
```

## 4. 일반 MBTI 비교

### 4.1 데이터 사용 범위

일반 MBTI는 다음에만 사용한다.

1. 사용자 자기이해 입력값 표시
2. 투자거울 타입과의 “차이 인식” 문구 생성
3. 구독관리 리포트에서 자기인식 변화 질문의 소재로 활용

일반 MBTI는 다음에 사용하지 않는다.

- F1~~F10/P1~~P7 점수 계산
- 타입 산출 공식
- 투자 행동 예측
- 투자 성과 추정
- 투자 조언/추천

### 4.2 비교 문구 원칙

| 금지                                 | 허용                                                                           |
| ------------------------------------ | ------------------------------------------------------------------------------ |
| `INTP라서 손절을 못 합니다.`         | `입력한 MBTI와 별개로, 최근 거래 기록에서는 손실 보유 시간이 길게 나타났어요.` |
| `E 유형은 단타에 유리합니다.`        | `평소 성향 입력값은 참고 정보이며, 점수는 거래 기록만으로 계산합니다.`         |
| `이 타입은 이런 코인을 사야 합니다.` | `다음 분석에서 줄었는지 볼 수 있는 행동 지표를 함께 보여드릴게요.`             |
| `당신은 원래 충동적입니다.`          | `최근 기록에서는 짧은 간격의 반복 거래가 상대적으로 많았어요.`                 |

### 4.3 비교 결과 예시

```text
평소 MBTI: INFJ
투자거울 타입: C-R-L-D · 추격형 단기 반응가

평소 자기이해와 달리, 거래 화면에서는 빠르게 반응한 흔적이 더 많이 보였어요.
이 결과는 성격 판단이 아니라 최근 거래 기록의 요약입니다.
```

### 2.4 공유 카드 스펙

예상 타입 카드와 기록된 타입 카드 모두 공유 가능해야 한다. 공유 카드는 저장 버튼보다 사용자가 직접 캡처하기 쉬운 세로형 카드 디자인을 전제로 한다.

포함:

- 타입명
- 4축 코드
- 한 줄 설명
- `coinmirror` 워터마크와 서비스 URL
- “예상 타입” 또는 “최근 거래 기록 기준” 표기

금지:

- 점수 숫자
- 금액
- 수익률
- 종목명

점수와 금액을 빼는 것이 손실회피로 인한 공유 차단을 줄이는 핵심 설계다.

### 2.5 타입 해석 구성

투자거울 타입 카드는 단순 라벨에서 끝나지 않고, 아래 4개 블록을 함께 보여준다.

| 블록               | 목적                                                 | 문구 원칙                                                                 |
| ------------------ | ---------------------------------------------------- | ------------------------------------------------------------------------- |
| 장점               | 현재 기록에서 비교적 안정적인 행동을 긍정적으로 확인 | “잘한다/고수”가 아니라 “과도하지 않다”, “점검 여지가 있다”처럼 회고형     |
| 주의할 점          | 다음 분석에서 먼저 확인할 행동 신호                  | “위험하다”보다 “먼저 줄었는지 확인하면 좋다”                              |
| 개선하면 좋은 편향 | 행동경제학 기반 편향 이름과 짧은 대응 원칙           | 투자 추천이 아니라 관찰/대기/점검 행동으로 제한                           |
| 유사 MBTI 비유     | 재미 요소와 공유성 강화                              | 반드시 “재미용 비유”라고 표시하고 실제 MBTI와의 상관/인과를 주장하지 않음 |

예시:

```text
투자거울 타입: 분산형 안정 관찰가

장점
- 급등 직후 따라 들어가는 비중이 과도하게 높지는 않아요.
- 거래 빈도가 극단적으로 흔들리기보다 관찰 가능한 리듬 안에 있어요.

주의할 점
- 손실 직후 빠르게 다시 진입하는 복구매수 패턴은 먼저 줄었는지 확인하면 좋아요.
- 한 종목 최대 비중 기준이 없어 자금 배분 축은 아직 확정하지 않았어요.

개선하면 좋은 편향
- 손실회피·만회 심리: 손실을 확정한 뒤 2시간은 같은 종목 재진입을 쉬는 원칙을 확인해 보세요.
- FOMO·주의 기반 매수: 급등 직후에는 30분 뒤에도 같은 판단인지 확인해 보세요.

유사 MBTI 비유
- ISTJ · INTJ에 가까운 “신중한 관찰 이미지”로 설명할 수 있어요.
- 이 비유는 재미용이며, 실제 성격검사 결과나 투자 성과와의 관계를 의미하지 않습니다.
```

### 4.5 유사 MBTI 비유 원칙 — 필수 안전장치

유사 MBTI는 “실제 성격 MBTI와 매칭”이 아니라, 거래 기록으로 보이는 행동 리듬을 MBTI식 언어로 가볍게 비유하는 기능이다. 타입이 첫 화면의 주역이 되었기 때문에 `재미용 비유`와 `최근 거래 기록 기준` 문구는 부가 설명이 아니라 카드 하단 필수 안전장치다. 작은 글씨로 숨기지 말고 카드 본문 하단에서 읽을 수 있는 크기로 표시한다.

| 투자거울 축 조합 | 유사 MBTI 비유 | 설명                                               |
| ---------------- | -------------- | -------------------------------------------------- |
| W + H            | ISTJ · INTJ    | 신중하게 관찰하고 장기 리듬을 유지하는 이미지      |
| C + R            | ESTP · ENTP    | 빠르게 반응하고 기회를 탐색하는 이미지             |
| L + N            | ISFJ · INFJ    | 익숙한 포지션을 오래 붙잡고 확신을 중시하는 이미지 |
| R + X            | ESTP · ESFP    | 짧게 확인하고 빠르게 정리하는 이미지               |

금지:

- `당신의 투자 MBTI는 실제 MBTI와 같습니다.`
- `INTJ라서 장기투자에 유리합니다.`
- `ESTP형은 단타에 적합합니다.`

허용:

- `유사 MBTI 비유는 재미용입니다.`
- `최근 거래 리듬만 놓고 보면 ISTJ·INTJ의 신중한 관찰 이미지와 가깝게 설명할 수 있어요.`
- `입력한 MBTI는 점수 계산과 타입 산출에 사용되지 않습니다.`

## 7. 타입명 생성 규칙

타입명은 16개 고정 라벨보다, 강한 축 순서로 조합해 만든다.

1. 가장 낮은 점수/강한 편향 축을 대표 수식어로 쓴다.
2. 두 번째 강한 축을 행동 스타일로 붙인다.
3. 마지막 명사는 평가가 아닌 관찰형 단어를 쓴다.

예시:

| 강한 축 | 타입명             |
| ------- | ------------------ |
| C + R   | 추격형 단기 반응가 |
| L + N   | 집중형 손실 보류가 |
| C + N   | 집중 추격 관찰가   |
| W + D   | 분산형 안정 관찰가 |
| R + X   | 짧은 점검형 반응가 |

금지 단어:

- 실패형
- 위험형
- 도박형
- 하수/고수
- 수익형/손실형
- 공격 추천/방어 추천
